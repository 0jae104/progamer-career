# 11.8 경제 설계: 큰돈의 쓸모 (v0.11.12)

작성 2026-11-23. 기준은 v0.11.11(`811ebe3`). 숫자는 모두 **자동 규칙(autoStep)으로 돌린 시뮬레이션**이며 사람의 소비 행동이나 만족도가 아닙니다. 사람이 해 본 평가는 0건입니다.

- **계약 시장의 후보**(결산 때마다 세어 봄, 7,944번): 자격을 통과한 구단 수의 중앙값 7(10%~90%: 0~25). 보여 준 세 곳 말고도 후보가 남은 시장이 67.3%. 해외에서 뛰는 동안 고국 1군 후보가 자격은 되는데 목록에 없던 시장이 14.1%.

읽은 것:
1. 돈은 8년차부터 빠르게 쌓이고, 단계형 투자는 7년차쯤 끝납니다. 그 뒤로 쓸 곳은 연봉의 6~10%인 시즌 프로젝트뿐입니다.
2. 편차가 큽니다(은퇴 잔액 10%~90%가 4억~144억). **연봉에 비례하는 값만으로는 쌓인 돈을 쓸 수 없고, 정해진 큰 값은 하위 커리어가 닿지 못합니다.** 그래서 성격이 다른 둘을 만들었습니다.
3. 계약 시장에는 보여 주지 않은 후보가 실제로 남아 있습니다. 에이전트가 "없는 제안을 만들어 낼" 필요가 없습니다.

## 2. 넣은 것

둘 다 기존 **시즌 프로젝트** 칸의 선택지입니다. 한 시즌에 집중 캠프·팬 캠페인·에이전트·아카데미 가운데 하나. 자동으로 사지 않고, 자동진행을 멈추지 않으며, 난수를 쓰지 않습니다.

### A. 전담 에이전트 — 현역의 선택 폭

| | |
|---|---|
| 값 | 연봉의 15%(최소 300만). 컨디션은 쓰지 않음 |
| 하는 일 | 다음 계약 시장(계약 만료 또는 스토브리그의 이적 요청)에서 **1군 후보 한 곳을 더** 보여 줌 |
| 어디서 찾나 | `genOffers()`가 **이미 자격을 통과시킨 후보** 가운데 세 자리에 들지 못한 것. 새 후보를 만들지 않고, 자격 조건(OVR·나이·실적·해외 조건)을 우회하지 않음 |
| 무엇을 고르나 | 해외에서 뛰는 중이고 목록에 고국 1군이 없으면 고국 1군(연봉이 가장 높은 곳) → 아니면 전력이 가장 강한 1군 |
| 보장 | 없음. 화면에 "조건을 보장하지 않는다"고 적음 |
| 더 볼 팀이 없으면 | 계약이 쓰이지 않고 **다음 시장까지 이어짐**. 그 사이에는 다시 살 수 없음 |
| 못 쓰고 은퇴하면 | 전액 환급(통산 수입에는 넣지 않음) |
| 기존 `homeSlot`과의 관계 | `homeSlot`이 이미 고국 제안을 올렸으면 에이전트는 고국 팀을 또 찾지 않고 강팀을 찾음. 같은 구단이 두 번 나오지 않음 |

**왜 이 효과인가.** 지금 목록은 "연봉이 높은 둘 + 하나"입니다. 연봉이 낮아 밀린 강팀이나 고국 팀을 보려면 운이 필요했습니다. 에이전트는 그 한 자리를 삽니다. "더 많은 돈"이 아니라 **"돈이 아닌 다른 기준의 선택지"**를 주므로, 산 사람이 늘 이기는 구조가 아닙니다(3절: 강팀을 고르면 우승은 늘고 수입은 줍니다).

**왜 1군 후보만인가.** 처음에는 남은 후보가 2군뿐이면 2군 제안이라도 가져오게 했습니다. 화면으로 보니 "같은 연봉의 다른 2군" 하나가 붙는 것은 낸 돈의 값을 하지 못했습니다. 그래서 1군이 없으면 쓰이지 않고 이어지게 바꿨습니다.

**왜 15%인가.** 1군 연봉의 중앙값(한국 1.67억)에서 2,500만 안팎으로, 집중 캠프(10%)보다 비쌉니다. 쌓인 자산에 견주면 큰돈이 아닙니다. **에이전트의 진짜 값은 돈이 아니라 그 시즌의 프로젝트 자리**(집중 캠프를 포기)입니다. 정책 비교에서 계약이 끝나는 해마다 사면 커리어당 3.5번, 3.1억을 씁니다.

### B. 유소년 아카데미 — 선수 인생에 남는 것

| | |
|---|---|
| 값 | 1단계 장학 후원 **3억** → 2단계 아카데미 설립 **10억** → 3단계 이름을 건 아카데미 **25억**(합계 38억). 연봉과 무관 |
| 한 시즌에 | 한 단계. 그 시즌의 프로젝트 자리를 씀 |
| 능력치·한계·인기·승률·커리어 점수 | **닿지 않음** |
| 시즌 중에 보이는 것 | ① 해마다 결산에 "아카데미 수료생 n명이 프로 팀에 들어갔다. 지금까지 m명." — n = 단계 + (인기 50 이상이면 1) + 해마다 0~1. ② 시즌을 시작할 때 감독 신뢰 +1 × 단계 |
| 은퇴한 뒤 | 은퇴 화면에 "은퇴 뒤" 문장(단계마다 다름: 후배의 경기를 봐 준다 / 코치 / 원장)과 단계·배출한 프로 수·들인 돈. 명예의 전당 기록에도 남음 |
| 목록에 보이는 때 | 다음 단계 값의 절반을 모았을 때부터. 그 전에는 "1억 5,000만을 모으면 나온다" 한 줄 |
| 실수 방지 | 값 버튼을 두 번 눌러야 삼(창을 띄우지 않음). 다른 곳을 누르면 풀림 |

**왜 성능 효과가 없는가.** 38억짜리가 승률을 올리면 "돈을 낸 쪽이 정답"이 되고, 하위 커리어는 구경만 합니다. 요청서의 문장 그대로 "우승을 살 수는 없지만 남길 이야기를 만들 수 있다"가 목표입니다.

**장식이 아닌 근거.** 단계·들인 돈·수료생 수가 저장되고, 해마다 결산에 반영되며, 은퇴 화면과 명예의 전당의 내용이 실제로 달라집니다(검사가 확인). 기존 시스템과 닿는 것은 감독 신뢰 하나이고, 크기는 작습니다(1단계 +1).

**왜 3억·10억·25억인가.** 잔고의 중앙값이 3억을 넘는 것이 6~7년차, 10억이 8~9년차, 25억이 10~11년차입니다. 돈이 되는 대로 사는 정책에서 91%가 1단계 이상, 46%가 3단계까지 갑니다. 하위 10%(은퇴 잔액 4억)는 1단계만 닿습니다. "의미 있는 비율이 살 수 있고, 모두가 다 사지는 못하는" 크기입니다.

## 3. 기존 상품과의 차이

| | 무엇을 사나 | 값 | 성능에 닿나 |
|---|---|---|---|
| 단계형 투자(장비·코치·식단) | 성장 속도·컨디션 | 합계 5.3억, 7년차쯤 끝 | 예 |
| 집중 캠프 | 한계 +1 | 연봉의 10% | 예 |
| 팬 캠페인 | 인기 | 연봉의 6% | 간접(연봉·방송) |
| **전담 에이전트** | 계약 시장의 선택지 하나 | 연봉의 15% | 아니오(고르는 팀에 따라 달라짐) |
| **유소년 아카데미** | 기록과 은퇴 뒤 | 3억·10억·25억 | 아니오(감독 신뢰 +1~3뿐) |

겹치는 효과를 이름만 바꿔 판 것은 없습니다.

## 4. 넣지 않은 것과 이유

- **새 탭·모달·상점 페이지**: 요청대로 기존 한 줄 안에서 해결.
- **자동 구매**: 둘 다 자동 관리 대상이 아님.
- **에이전트의 2군·연습생 제안**: 가치가 작아 뺌(2절).
- **에이전트가 협상 확률이나 연봉을 올리는 효과**: "돈을 내면 돈을 더 번다"가 되어 뺌.
- **아카데미의 성장·한계·인기 효과**: 캠프·코치·팬 캠페인과 겹침.
- **커리어 점수·별명을 바꾸는 효과**: 명예의 전당의 순위가 돈으로 바뀌면 안 됨.
- **금융·부동산·주식**: 다른 게임이 됨.
- **은퇴 잔액을 0에 가깝게 만드는 조정**: 하지 않음. 아카데미를 끝까지 가도 중앙값 12억이 남음.

## 5. 지속·소모·예외

| 경우 | 에이전트 | 아카데미 |
|---|---|---|
| 같은 시즌에 다시 | 못 삼 | 못 삼 |
| 저장하고 다시 열기 | 계약 유지, 다시 못 삼 | 단계 유지 |
| 다른 구단으로 이적 | 추천 제안과 계약하면 그것이 이적. 계약은 그 시장에서 끝남 | 그대로(감독 신뢰는 새 팀에서도 시즌 시작 때) |
| 계약 시장이 열렸는데 더 볼 팀이 없음 | 이어짐 | – |
| 시장이 열리지 않는 해(잔류) | 이어짐 | – |
| 은퇴 | 못 썼으면 환급 | 은퇴 화면·명예의 전당에 남음 |
| 무소속(방출 뒤) | 살 수 없음(소속이 있을 때만) | 살 수 없음 |
| v0.11.11로 내려 열기 | 파일은 열림. 계약은 쓰이지도 환급되지도 않음 | 파일은 열림. 값은 남지만 효과·기록은 없음 |

## 6. 이것이 "고민"이 될 수 있는 이유 (가설)

- 계약이 끝나는 해: 집중 캠프(한계 +1)를 할지, 에이전트로 팀을 넓게 볼지.
- 강팀의 낮은 연봉과 약팀의 높은 연봉이 나란히 놓였을 때 무엇을 고를지.
- 10억이 모였을 때: 2단계를 세울지, 25억까지 기다릴지, 그 시즌 캠프를 포기할지.

확인하지 못한 것: 사람이 실제로 고민하는지, 에이전트의 "더 볼 팀이 없었다"(정책 비교에서 산 횟수의 약 30%는 그 시장에서 쓰이지 못하고 이어짐)가 실망인지, 아카데미가 보람인지 장식인지.
