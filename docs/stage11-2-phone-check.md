## 1. 5분 확인 (일곱 가지)

| # | 할 일 | 이렇게 되면 통과 | 결과 |
|---|---|---|---|
| 1 | 홈을 본다 | 스크롤하지 않고 컨디션·신뢰·자금, 이번 달 할 일 다섯 칸, 다음 목표, 맨 아래 진행 버튼이 다 보인다 | |
| 2 | **할 일 바꾸기**: 다섯 칸 중 다른 것을 누른다 | 한 번 눌러 바뀌고, 바로 아래에 그 일의 효과와 컨디션 소모가 나온다 | |
| 3 | **▶▶ 자동진행**을 처음 누른다 | 무엇을 맡기고 어디서 멈추는지 설명이 뜬다. 아직 달은 넘어가지 않는다. "시작"을 누르면 달이 이어서 넘어간다 | |
| 4 | 넘어가는 동안 지켜본다 | 버튼을 더 누르지 않아도 여러 달이 이어진다. 평범한 사건에서는 멈추지 않는다 | |
| 5 | **Ⅱ 멈춤**을 누른다 | 한 번 눌러 바로 선다. 위쪽에 "멈춤을 눌러 멈췄다"와 지난 진행 요약이 나온다 | |
| 6 | 다시 ▶▶ 자동진행 → 저절로 멈출 때까지 둔다 | 창(계약 제안·시즌 결산·경기 준비 등)이 뜨면서 멈추고, 왜 멈췄는지 한 줄이 보인다. "자동 선택 n건"을 누르면 대신 고른 사건이 나온다 | |
| 7 | 자동진행 중에 홈 버튼으로 나갔다가 돌아온다 | 돌아왔을 때 멈춰 있다("화면이 가려져 멈췄다"). 그동안 달이 넘어가지 않았다 | |

덤으로 볼 것

- 경기의 승부처에서 "감독 판단에 맡긴다"를 누르면 진행된다(v0.11.1에서는 눌리지 않았습니다).
- "자산" 탭에서 자동 관리 스위치를 켜고 끌 수 있고, 켜지 않은 항목에는 돈이 나가지 않는다.
- 새 커리어 → 선수 등록이 두 화면이고, 얼굴을 고르지 않아도 넘어간다.
- 맨 아래 버튼이 폰의 하단 바(홈 표시줄)에 가려지지 않는다.
- 글자가 작아 읽기 힘든 곳, 잘못 누르기 쉬운 버튼이 없다.
