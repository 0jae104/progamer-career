# 11.2단계 결과: 자동진행 · 가벼운 홈 · 장기 밸런스 (v0.11.2)

작성 2026-11-21. 대상 v0.11.1(`a3e1926`) → v0.11.2.

v0.11.1을 실제로 해 본 사람들의 말: "한눈에 안 보인다", "한 화면에 몰아놓아 더 불편하다", "다음 중요한 순간을 눌러도 조금 가다 멈춘다", "이번 달 할 일을 바꾸기 어렵다", "이전 버전이 낫다". 그리고 돈 쓸 곳, 중국 리그에서의 한국 복귀 제안, 노력형의 성장, 선수 생성과 얼굴.

**먼저 한계부터.** 이 문서의 숫자는 모두 node와 PC 헤드리스 크롬(폰 크기 에뮬레이션)에서 잰 것입니다. 실제 폰, 배포 주소, 사람은 하나도 없습니다. "v0.11.1보다 낫다"는 것은 조작 수·화면 길이·멈춘 이유 같은 잴 수 있는 것으로만 보였고, **사람이 그렇게 느끼는지는 미검증**입니다.

## 1. 플레이 흐름이 어떻게 달라졌나

**v0.11.1의 1군 한 시즌**: "다음 중요한 순간"을 누르면 평균 1.6개월 뒤에 멈췄습니다. 멈춘 이유의 65%는 평범한 사건(선택지 둘 중 하나를 고르는 창)이었습니다. 그래서 한 시즌에 진행 버튼을 약 8번, 사건을 포함한 선택을 9번 눌렀습니다. 할 일을 바꾸려면 큰 버튼을 눌러 목록을 편 뒤 골라야 했고(두 번), 320px 폰에서는 목록이 화면 밖으로 나가 스크롤이 필요했습니다. 승부처의 "감독 판단에 맡긴다"는 눌러도 반응이 없었습니다.

**v0.11.2의 1군 한 시즌**: 홈을 열면 스크롤 없이 상태 세 가지, 할 일 다섯 칸, 다음 목표, 진행 버튼이 보입니다. 할 일은 칸을 한 번 누르면 바뀝니다. "▶▶ 자동진행"을 한 번 누르면 평범한 사건은 미리 고른 성향대로 넘어가고, 토너먼트의 경기 준비·계약·시즌 결산처럼 직접 정할 것이 나올 때 섭니다. 한 시즌에 진행 버튼은 약 2번, 직접 고르는 선택은 4~5번입니다. 멈추면 왜 멈췄는지 한 줄이 나오고, 대신 고른 사건은 "자동 선택 n건"에서 볼 수 있습니다.

- 위 세 줄(한 달씩·다음 중요한 순간)은 시즌 끝 상태가 글자 단위로 같습니다. 자동진행은 사건을 성향대로 고르므로 결과가 다를 수 있습니다(누른 횟수만 비교).

## 2. P0-1: "감독 판단에 맡긴다"가 눌리지 않던 결함

- **원인**: v0.11.1에서 내가 넣은 자동 관리 스위치와 승부처의 자동 선택 버튼이 같은 명령 이름(`data-act="auto"`)을 썼습니다. 클릭 처리의 `switch`에서 앞쪽(자동 관리)에 먼저 걸려 승부처 쪽에는 닿지 않았습니다. v0.11.1의 검사는 이 버튼을 누르지 않아 잡지 못했습니다.
- **재현**: 수정 전 코드에서 `test/browser/auto.js`를 돌린 기록이 `docs/qa-logs/stage11-2/auto-clash-before-fix-v0.11.1.txt`입니다("감독 판단에 맡긴다를 눌렀는데 승부처가 진행되지 않음(장면 moment)").
- **수정**: 명령을 `shop-auto` / `mom-auto`로 나누고, 자동진행 쪽은 `ap-go`·`ap-start`·`ap-pause`·`ap-set`·`ap-style`·`ap-rest`·`ap-match`·`ap-spd`로 따로 두었습니다. 결과 화면에 "자동 선택(감독 판단): …"을 표시합니다.
- **재발 방지**: `test/static.js`가 `switch`의 같은 이름 `case`와 처리하는 곳이 없는 명령을 찾습니다(수정 전 코드에서 "중복 case auto"로 실패하는 것을 확인). CI에 넣었습니다. `auto` 묶음 A는 버튼을 실제로 눌러 장면이 진행되고 자동 관리 설정이 바뀌지 않는 것을, `play` 묶음 A는 반대로 자동 관리 스위치가 달을 넘기거나 장면을 건드리지 않는 것을 봅니다.

## 3. P0-2: 자동진행

### 3-1. 버튼

- **▶ N월 진행**: 한 달. 필요한 선택은 직접 합니다(예전의 수동 플레이 그대로).
- **▶▶ 자동진행**: 달을 계속 넘깁니다. 진행 중에는 그 자리가 **Ⅱ 멈춤** 하나로 바뀝니다.
- **설정**: 사건을 고르는 성향(안정·균형·도전), 컨디션이 낮으면 휴식(기본 켜짐), 평범한 토너먼트 경기도 맡기기(기본 꺼짐), 속도(보통 0.26초/달 · 빠름 0.04초/달).
- 처음 누르면 무엇을 맡기고 어디서 멈추는지 설명하는 창이 먼저 뜨고, "시작"을 눌러야 진행합니다. 그 뒤로는 한 번 눌러 바로 시작합니다. 새 커리어와 예전 저장 모두 자동진행은 꺼진 상태입니다.
- 멈춘 뒤에 저절로 다시 시작하지 않습니다. 다시 누를 때만 이어 갑니다.

### 3-2. 중단 정책표 (`js/engine.js`의 `AP_RULE`)

| 장면 | 자동진행이 하는 일 |
|---|---|
| 월간 보고(평범한 달) | 요약에 쌓고 넘김 |
| 사건의 결과 | 요약에 쌓고 넘김 |
| **사건 선택** | 성향대로 고르고 계속. **멈추는 경우**: 생애에 한 번뿐인 사건 5종(부모님의 반대, 집 생각, 첫 공식전, 낯선 번호, 눈에 밟히는 이름) · 남은 선택지가 돈이 드는 것뿐일 때 · 돈으로 피할 수 있는데 남은 것이 성향이 꺼리는 도박뿐일 때(예: 손목 통증의 "참고 뛴다") |
| 경기 준비 | 기본은 **멈춤**. "평범한 경기도 맡기기"를 켰고 결승·국제전(미드시즌 컵, 월드 파이널, 네이션스컵)·라이벌 팀 상대가 아니면 전략을 정해 시작(안정 = 안정적으로 운영, 도전 = 강하게 압박, 균형 = 표시된 승률이 가장 높은 전략) |
| 승부처 · 세트 결과 · 경기 결과 | 자동진행이 방금 시작한 시리즈일 때만 처리(승부처는 "감독 판단"과 같은 규칙). 사람이 시작한 시리즈면 **멈춤** |
| 계약 제안 · 스토브리그(잔류·이적·은퇴) · 입단 테스트 · 구단 고르기 | **항상 멈춤**. 대신 정하지 않음 |
| 성장 카드 | **항상 멈춤** |
| 시즌 결산 | **항상 멈춤** |
| 알림(콜업, 2군행, 방출, 부상, 우승, 스플릿 MVP, 올해의 선수, 결승의 라이벌, 테스트 합격 등) | **항상 멈춤** |
| 은퇴 | **항상 멈춤** |
| 처음 안내가 달린 월간 보고 | **멈춤** |
| **표에 없는 장면** | **멈춤**(모르면 멈춘다) |

사건 성향: 안정 = 확률 판정이 없는 선택지(없으면 성공 확률이 가장 높은 것) · 균형 = 성공 확률 60% 이상인 도전이 있으면 하고 아니면 판정 없는 것 · 도전 = 35% 이상이면 도전. 돈이 드는 선택지와 고를 수 없는 선택지는 어떤 성향도 고르지 않습니다.

화면 쪽에서 멈추는 경우: 멈춤 버튼(또는 진행 중의 아무 입력) · 다른 탭으로 이동 · 화면이 가려짐(`visibilitychange`, `pagehide`) · 다른 브라우저 탭이 저장을 바꿈 · 오류 · 36개월 연속(안전장치).

멈춘 이유는 요약 맨 위에 한 줄로 나옵니다("계약 제안이 와서 멈췄다", "경기 준비: 전략을 고를 차례라 멈췄다", "한 번뿐인 사건이라 직접 고르도록 멈췄다" 등 20여 가지).

### 3-4. 구현과 안전

- **화면을 막지 않음**: 한 번 부르면 한 달만 처리하는 `G.autoMonth()`를 화면이 `setTimeout`으로 이어 부릅니다. 달마다 화면 전체를 다시 그리지 않고 진행 줄과 위쪽 숫자만 바꿉니다. CPU를 6배 느리게 한 에뮬레이션에서 10개월에 약 0.5초였습니다.
- **예약 작업은 하나**: 시작 버튼을 6번 연달아 눌러도 1.1초에 5개월을 넘지 않습니다(0.25초/달 설정).
- **저장**: 달마다 저장합니다(기존 `next()`/`resolve()`의 저장 그대로). 진행 중에 새로 고치면 다시 열었을 때 멈춰 있고, 마지막으로 끝낸 달에서 이어집니다. 자동 관리의 중복 결제·음수 잔고는 0이었습니다(자동 관리가 실행된 200여 달).
- **결정론**: 자동진행이 엔진을 부른 순서(할 일 바꾸기 → 다음 달 → 장면 처리)를 기록해 두었다가 새 엔진에서 같은 시드로 그대로 다시 부르면 최종 상태와 다음 난수가 같습니다(45커리어 × 시드 2개 모두). 타이머는 난수를 쓰지 않습니다. 화면에서 돌린 결과와 엔진만으로 돌린 결과도 같습니다(`auto` 묶음 B).
- **기록**: 대신 고른 것은 최근 30건이 저장에 남고(기록 탭 → "최근 자동 선택"), 이번 진행분은 요약의 "자동 선택 n건"에 결과와 함께 나옵니다. 예: `docs/qa-logs/stage11-2/auto-log-sample.txt`.
- **설정의 저장**: 성향·휴식·경기 맡기기·속도는 커리어 저장 안(`ap`)에 있어 백업·복원을 따라갑니다. "진행 중"이라는 상태는 저장하지 않습니다.
- **검사용 `autoStep()`은 그대로**이고 사용자에게 노출하지 않았습니다(체험전 준비에만 쓰던 기존 용도 그대로).

### 3-5. 재현법

```
# 엔진 검사(결정론, 정책표, 정지 규칙, 성향)
node test/autoplay.js 45 --seed=1
# 화면 검사(명령 충돌 회귀, 첫 설명, 연속 진행 10시드, 멈춤, 연타, 가려짐, 탭 이동, 새로 고침, 다른 탭, 느린 기기)
PG_CHROME=/usr/bin/google-chrome node test/browser/run.js auto
# 손으로: npx serve . (또는 아무 정적 서버) → 새 커리어 → 첫 3개월(안내)을 넘긴 뒤 ▶▶ 자동진행 → 시작 → Ⅱ 멈춤
```

자동 선택이 예상과 달랐다면: 기록 탭의 "최근 자동 선택"에 사건 이름·고른 선택지·표시된 확률이 남아 있습니다. 같은 사건·같은 확률·같은 성향이면 항상 같은 선택지를 고릅니다(난수를 쓰지 않음).

**원인 두 가지**

1. **목록에서 밀림**: 제안 목록은 연봉 상위 2개 + 무작위 1개였습니다. 연봉은 리그 배율(중국 1.5, 북미 1.35, 유럽 1.15, 한국 1.0)을 따르므로, 한국 팀의 제안은 후보에 들어도(75%) 상위 2개에 못 들고 무작위 한 자리에 걸려야만 보였습니다(19%). "성적을 내도 한국 팀이 안 부른다"로 보인 것의 대부분이 이것입니다.
2. **나이**: 24세를 넘으면 한 살마다 요구 OVR이 4씩 오릅니다. 30세면 +24라 사실상 불가능했습니다(10%).

참고: `S.home`(국적)은 해외로 옮겨도 덮어쓰지 않습니다. 코드에서 확인했고, 한국 국적 선수에게 한국 구단은 해외 진출 조건(OVR 76 또는 인기 45) 없이 항상 평가 대상입니다.

**수정(최소)**

- 해외에서 **직전 시즌에 1군 20경기 이상, 평균 평점 6.3 이상**을 낸 선수에 한해
  - 고국 1군 제안이 후보에 들었는데 상위 2개에 없으면 **세 번째 자리를 그 제안에 줍니다**(고국 팀 중 연봉이 가장 높은 것).
  - 고국 구단이 볼 때의 **나이 페널티를 0.75배**로 합니다(0.5배는 30세 이상·성적 준수가 77%까지 올라 과했고, 1배는 11%에 머뭅니다).

- 보장은 아닙니다. 성적을 내도 후보에 들지 못하면(16%) 제안은 없습니다.
- **화면**: 고국 제안에는 "한국 리그 복귀 제안. 해외에서 쌓은 1군 경력을 보고 연락해 왔다."가 붙고, 제안이 없을 때는 "한국 리그의 1군 제안은 없었다. 문턱이 가장 낮은 팀도 OVR 78 안팎을 원한다(지금 74, 나이 때문에 +6). 한 시즌 20경기 이상, 평균 평점 6.3 이상이면 고국 팀이 더 눈여겨본다."처럼 이유를 한 줄 적습니다(숫자는 그때의 값).

- **돈 쓰는 선택(자산 탭, 기본 꺼짐)**
  - **팬 미팅**(월 250만): 인기 +2, 컨디션 −6. 인기는 연봉 제안과 방송 수입에 들어갑니다. 자동으로 켜 두면 컨디션이 40 미만인 달에는 건너뜁니다.
  - **전술 분석가**(월 350만): 판단력 +0.3, 숙련 폭 +0.2(한계까지). 나이가 들어 성장 배율이 낮아져도 같은 만큼 오릅니다. 더 오를 곳이 없으면 건너뜁니다.
  - 기존 다섯 항목과 자동 관리의 규칙(남겨 둘 돈, 한 달 상한, 건너뛴 이유)은 그대로이고 같은 화면·같은 스위치를 씁니다. 별도 구매 창은 없습니다. 사지 않으면 판정이 예전과 같습니다.
  - **범위를 줄인 것**: 요청서의 예 세 가지 중 "방송 장비"는 넣지 않았습니다. 두 항목이 실제로 재미를 주는지 본 뒤에 판단할 일입니다. **사람이 좋다고 확인한 것은 없습니다.**

## 9. 알려진 문제와 약점

- **자산 탭이 깁니다.** 투자 항목이 일곱 개라 320px에서 화면 약 3장입니다(v0.11.0의 투자 탭은 1.5장). 항목을 접는 것은 다음 후보입니다.
- **1군에서는 여전히 자주 섭니다.** 기본 설정(경기는 직접)에서는 토너먼트 달마다 경기 준비에서 멈춥니다. 요청서와 이전 지시("경기 전략·라이벌전에서는 반드시 멈춘다")에 맞춘 기본값이지만, "또 멈춘다"는 말이 나올 수 있습니다. "평범한 경기도 맡기기"를 켜면 결승·국제전·라이벌 팀만 남습니다.
- **시즌 결산에서 항상 섭니다**(멈춘 이유의 절반). 이어서 성장 카드와 스토브리그가 오기 때문에 그대로 두었습니다.
- **자동 휴식이 잦습니다.** 컨디션 40 미만에서 쉬는 규칙이라 훈련 강도에 따라 서너 달에 한 번 쉽니다. 끌 수 있습니다.
- **도전 과제 알림이 위쪽 상태 줄을 5초쯤 가립니다**(기존 동작). 자동진행으로 한꺼번에 달성하면 더 눈에 띕니다.
- **천재형이 상대적으로 최하위가 됐습니다**(5-1의 주의 1).
- **홈에서 소식을 뺐습니다.** 지난 진행 요약은 있지만 예전처럼 소식 목록을 홈에서 보던 사람은 기록 탭으로 가야 합니다.
- **커밋 분리**: P0는 세 커밋(결함 수정 / 자동진행 엔진 / 화면)으로 나눴지만, P1 네 가지는 같은 파일을 고쳐 한 커밋에 들어갔습니다.
