# 폰으로 하는 핵심 12항목 (10~15분)

`docs/mobile-qa.md`의 66항목 가운데 가장 중요한 12개를 순서대로 따라 하는 안내입니다. 폰 한 대, 브라우저 하나로 합니다. 안드로이드 크롬, 삼성 인터넷, 아이폰 사파리 가운데 어느 것이든 좋고, 여러 개를 하면 더 좋습니다.

**현재 상태(v0.11.2, 2026-11-21): 이 양식으로 돌아온 결과는 아직 없습니다.** 소유자가 폰에서 플레이해 정상 작동을 확인했다고 알려 왔지만 항목별 결과는 받지 못했습니다. 이 문서를 만든 개발 환경에는 폰이 없습니다. v0.11.1의 플레이 화면을 보는 3분 확인은 `docs/stage11-1-phone-check.md`, 경기의 재미를 보는 3분 체험은 `docs/stage11-phone-playtest.md`에 따로 있습니다.

주소: https://0jae104.github.io/progamer-career/

## 시작하기 전에 (꼭 읽기)

- **평소에 이 게임을 하던 브라우저라면 먼저 백업합니다.** 기록실 → 백업 → "백업 파일 내려받기". 파일이 폰에 실제로 저장됐는지 확인합니다(안드로이드: 내 파일 → 다운로드, 아이폰: 파일 앱 → 다운로드).
- 이 점검은 **사이트 데이터를 지우지 않습니다.** 다만 10번(복원)은 지금 저장을 백업 파일의 내용으로 바꿉니다. 9번에서 방금 받은 파일로 복원하므로 결과는 같지만, 불안하면 평소에 게임을 하지 않는 브라우저에서 하세요.
- 평소 하던 커리어가 있다면 2번의 "새 커리어"가 그것을 덮어씁니다(게임이 한 번 더 묻습니다). **하던 커리어를 지키려면 평소에 쓰지 않는 브라우저에서 하거나**, 위의 백업을 받아 두었다가 점검이 끝난 뒤 그 파일로 복원합니다.
- 시크릿(사생활 보호) 창은 쓰지 않습니다.
- 같은 게임이 다른 탭에 열려 있으면 먼저 닫습니다.
- 안 되는 것이 있으면 **그 화면을 캡처**합니다(안드로이드: 전원 + 음량 아래, 아이폰: 전원 + 음량 위).

## 순서

| # | 할 일 | 이렇게 되면 통과 | 표의 번호 |
|---|---|---|---|
| 1 | 주소를 연다 | 타이틀 화면이 뜨고 맨 아래에 `v0.11.4`가 보인다. 글자가 깨지지 않는다 | 1-1 |
| 2 | "새 커리어" → 아이디 칸을 눌러 한글로 입력 | 키보드가 올라온 상태에서 화면을 내려 포지션과 "시작" 버튼까지 갈 수 있다 | 1-3, 1-3c |
| 3 | 포지션 하나를 누른다 → 설명이 펼쳐진다 → "시작" → 구단 선택 | 설명 글이 잘리지 않는다. 구단 세 곳이 모두 보이고 눌린다 | 1-4 |
| 4 | 아래 "○월 진행" 버튼을 **빠르게 두 번** 누른다 | 한 달만 지나간다(창이 하나만 뜬다) | 2-1 |
| 5 | 서너 달 진행한 뒤, 브라우저를 최근 앱 목록에서 밀어 완전히 닫고 다시 연다 → "이어하기" | 닫기 전과 같은 선수, 같은 달이다 | 2-9 |
| 6 | 맨 아래 "▶▶ 자동진행"을 눌러 가며 은퇴할 때까지 진행(5~10분). 승부처·계약 창은 아무거나 고른다 | 멈춰서 넘어가지 않는 화면이 없다. 버튼이 화면 밖으로 나가지 않는다 | 2-2 |
| 7 | 은퇴 화면 → "커리어 카드 만들기" → "PNG 저장" | 카드 그림이 보이고, 저장한 그림이 갤러리(사진) 또는 다운로드에 있다 | 3-1 ~ 3-3 |
| 8 | 타이틀 → "기록실" → 명예의 전당 | 방금 은퇴한 선수가 있다. 누르면 상세가 열린다 | 3-8 |
| 9 | 기록실 → "백업" → "백업 파일 내려받기" | 백업 파일(`.json`)이 폰에 저장된다 | 5-1 |
| 10 | 같은 화면에서 "백업 파일 고르기" → 방금 파일 → 미리 보기 확인 → "복원" | 타이틀에 "백업을 복원했다"가 뜨고, 명예의 전당이 그대로다 | 5-2 ~ 5-4 |
| 11 | 비행기 모드를 켜고 브라우저를 완전히 닫았다가 주소를 다시 연다 | 타이틀이 뜨고 "오프라인 상태다" 안내가 보인다. 기록실이 열린다. 끝나면 비행기 모드를 끈다 | 6-3, 6-4 |
| 12 | 게임 화면과 창들에서 맨 아래 버튼을 본다 | 폰의 하단 바(홈 막대·주소창)에 가려 눌리지 않는 버튼이 없다 | 1-8 |

아이폰에서 7번의 저장 위치는 "파일에 저장" 또는 "이미지 저장" 가운데 무엇이 뜨는지 적어 주세요. 11번이 처음에 실패하면 온라인에서 한 번 새로 고친 뒤 다시 해 봅니다(처음 연 직후에는 오프라인용 파일을 아직 다 받지 못했을 수 있습니다). 그것도 결과에 적습니다.

## 결과 보내기 (복사해서 채워 주세요)

```
폰 모델:            (예: 갤럭시 S23)
OS 버전:            (예: 안드로이드 15 / iOS 18.1)
브라우저와 버전:    (예: 삼성 인터넷 27.0)
날짜:
타이틀의 버전 숫자:

1  타이틀·버전:        O / X
2  키보드와 버튼:      O / X
3  포지션·구단:        O / X
4  두 번 누르기:       O / X
5  닫았다 이어하기:    O / X
6  은퇴까지 진행:      O / X
7  카드 PNG 저장:      O / X   (저장된 곳:            )
8  명예의 전당:        O / X
9  백업 내려받기:      O / X   (저장된 곳:            )
10 복원:               O / X
11 오프라인:           O / X
12 하단 버튼:          O / X

X인 항목: 무엇을 눌렀고 어떻게 됐는지 + 캡처
하지 못한 항목: 번호만
```

하지 못한 항목은 `미실행`으로 남습니다. O라고 받은 것만 `docs/mobile-qa.md`에 표시합니다.

## 판단 기준

- **저장이 사라졌다, 화면이 열리지 않는다, 진행이 막혔다, 복원이 안 된다** → P0. 비공개 베타를 시작하지 않고 먼저 고칩니다. 이때는 브라우저 데이터를 지우지 말고 그대로 둔 채 알려 주세요.
- 글자가 잘린다, 버튼이 작다, 저장 위치를 찾기 어렵다 → P1 또는 P2. 적어 두고 진행합니다.
- 12개가 모두 O이면 그 브라우저는 "핵심 흐름 확인됨"입니다. 66항목 전체는 `docs/mobile-qa.md`의 순서(약 40분)를 따릅니다.
