# 11.5단계 설계: 한 시즌이 기억에 남게 (v0.11.5)

작성 2026-11-22. 이 문서는 **실제로 구현한 규칙**만 적습니다. 구현하지 않은 것은 맨 아래에 따로 있습니다.

목표 한 문장: 선수 한 명으로 한 시즌을 보냈을 때 자기 팀·라이벌·중요한 선택 하나가 기억에 남고 다음 시즌의 목표가 생긴다.

원칙 세 가지

1. **재료는 이미 있는 실제 기록뿐.** 소속, 1군 경기 수, 평점, 우승, 라이벌과의 맞대결 결과. 없던 일을 문장으로 만들지 않는다.
2. **판정을 건드리지 않는다.** 시즌 목표·라이벌 문장·구단 소개는 경기 결과·성장·난수에 들어가지 않는다(유일한 예외는 5절의 분석 자료이고, 사지 않으면 0이다).
3. **창과 누름을 늘리지 않는다.** 새 탭·새 창·새 확인 버튼 없음. 기존 화면의 한 줄씩.

## 1. 시즌 목표

### 언제 고르나

- **시즌 결산 창의 확인 버튼 자리**에서 고릅니다. "스토브리그로" 버튼 하나가 있던 자리에 목표 2~3개가 버튼으로 놓이고, 하나를 누르면 그대로 스토브리그로 넘어갑니다. 누름 수는 전과 같습니다(1번).
- 자동진행은 원래 시즌 결산에서 멈추므로 멈춤이 늘지 않습니다. 대신 골라 주지도 않습니다.
- 고르지 않고 넘어가는 경로(검사용 자동 규칙, 예전 화면)에서는 첫 번째 후보가 됩니다.
- **첫해**는 고르는 창 없이 "2군 콜업"이 기본 목표입니다.
- **예전 저장**: 진행 중인 시즌에는 목표가 없습니다. 다음 시즌 결산에서 처음 고릅니다(그 결산에는 "지난 목표의 판정"이 나오지 않습니다).
- 시즌당 한 번. 시즌 도중에 바꿀 수 없습니다.

### 후보 (지금 소속과 지난 시즌 기록에서 가능한 것만)

| 목표 | 누구에게 | 달성 조건(그 시즌의 실제 기록) |
|---|---|---|
| 2군 콜업 | 연습생(기본) | 시즌이 끝났을 때 연습생이 아니다 |
| OVR n 도달 | 연습생·2군 | 시즌이 끝났을 때 OVR이 n 이상(n = 지금 + 3 / 2 / 1, 나이 20세 이하 / 24세 이하 / 그 위) |
| 1군 무대에 서기 | 2군(기본) | 1군 소속이 됐거나 1군 경기를 1번 이상 뛰었다 |
| 1군 14경기 이상 출전 | 1군인데 지난 시즌 1군 출전이 14경기 미만(기본) | 1군 출전 14경기 이상 |
| 플레이오프 진출 | 1군, 지난 시즌 팀이 플레이오프에 못 감 | 팀이 1군 플레이오프 시리즈를 치렀다 |
| 플레이오프 시리즈 승리 | 1군, 지난 시즌 진출했지만 시리즈 승리 없음 | 내가 뛴 1군 플레이오프 시리즈를 1번 이상 이겼다 |
| 1군 대회 우승 | 1군, 지난 시즌 플레이오프 시리즈를 이겨 봄 | 그해 1군 대회 우승 1번 이상 |
| 1군 평균 평점 x 이상 | 1군, 지난 시즌 12경기 이상 출전 | 12경기 이상 뛰고 평균 평점 x 이상(x = 지난 시즌 + 0.2, 6.3~7.2 사이) |
| (라이벌)에게 올해 상대 전적 우세 | 2군·1군, 같은 리그·같은 군의 다른 팀에 뛰는 라이벌이 있을 때 | 그해 그 라이벌과의 맞대결에서 승이 패보다 많다 |

- 후보는 최대 3개. 연습생에게 우승·플레이오프·라이벌 목표는 나오지 않습니다.
- 라이벌 후보는 한 명: 토너먼트에서 진 상대 → 지난 맞대결에서 진 상대 → 통산 전적이 밀리는 상대 순으로 고릅니다.
- 지난 시즌에 이루지 못한 목표가 다시 후보에 오르면 설명 앞에 "지난 시즌에 이루지 못했다. 재도전."이 붙습니다.

### 판정

- **달성 / 미달성 / 판정 없음** 세 가지. "판정 없음"은 판정할 일이 없었던 경우입니다: 라이벌과 그해 한 번도 맞붙지 않았다(내가 팀·리그를 옮겼거나 상대가 떠났다), 평점 목표인데 12경기를 못 뛰었다, 1군 일정을 치르지 못했다.
- 결산 창에 판정과 이유가 한 줄로 나옵니다. 이유는 숫자 그대로입니다(예: "1군 9경기. 14경기에 5경기가 모자랐다.").
- **보상은 없습니다.** 능력치·신뢰·인기·돈·승률 어느 것도 바뀌지 않습니다. 남는 것은 결산의 한 줄, 소식 목록의 한 줄, 기록 탭의 "시즌 목표 — n번 달성 / m번"(최근 24시즌)입니다.
  - 이유: 보상을 주면 경기 결과가 달라져 지금까지 맞춘 밸런스를 다시 봐야 하고, "목표를 고르는 것이 이득"이 되면 선택이 아니라 숙제가 됩니다. 먼저 목표가 있다는 것만으로 한 시즌이 기억에 남는지를 봅니다.

### 평소에 보이는 곳

- 홈의 "다음 목표" 칸 안에 한 줄: "올해 목표 1군 14경기 이상 출전 9/14경기". 새 카드는 없습니다. 작은 화면이나 라이벌전 줄이 뜨는 달에는 "다음 목표" 제목 줄을 접어 높이를 지킵니다.

### 저장

- `goal`(올해 목표: 연차, 종류, 이름, 필요한 숫자, 라이벌이면 상대와 고를 때의 전적), `goalLog`(지난 판정, 최근 24개). 둘 다 없어도 되는 항목이고, 이상하면 버립니다.

## 2. 구단 소개

- 32개 구단에 **한 단어 색깔 + 한 문장**을 붙였습니다(`js/data.js`의 `IDT`). 이름·ID·전력은 그대로입니다.
- **글일 뿐입니다.** 전력과 승률에는 들어가지 않습니다. 경기 준비 화면의 상대 소개에는 "팀 분위기 소개다. 승률 계산에는 들어가지 않는다"고 적습니다.
- 문장은 기본 전력 순서와 어긋나지 않게 썼습니다(리그 1~2위권 = 우승을 다투는 팀, 하위권 = 기회가 많은 팀). 다만 구단 전력은 해마다 조금씩 흔들리므로 소개는 "그 팀의 내력"이지 "올해 순위"가 아닙니다. 올해 순위는 제안 화면의 "리그 8팀 중 n위"가 말합니다.
- 보이는 곳: 입단할 구단 고르기, 계약 제안, 리그 탭 맨 위(내 팀), 경기 준비 화면 맨 아래(상대 팀).
- **제안의 매력·부담 한 줄**: 이미 화면에 있던 사실(리그 순위, 옮기면 주전인지, 내 OVR과 팀 전력의 차)을 한 문장으로 묶습니다. 예: "우승을 다투는 팀이지만 벤치에서 시작한다. 트로피에 가깝고 출전은 멀다." / "성적은 낮은 팀이지만 바로 주전으로 뛴다. 경기 수를 쌓기 좋다." 순위 2위 이내 = 우승을 다투는 팀, 뒤에서 3팀 = 성적이 낮은 팀.

## 3. 라이벌 서사

새 사건·새 창·새 대사는 없습니다. 맞대결과 해 넘김에서 **사실 네 가지를 적어 두고**, 문장은 그 값에서만 만듭니다.

| 적어 두는 것 | 언제 | 내용 |
|---|---|---|
| `last` | 맞대결마다 | 지난 맞대결의 연차·월·승패 |
| `run` | 맞대결마다 | 내 연승(+)·연패(−) 수 |
| `ko` | 토너먼트 시리즈에서 졌을 때 | 그 연차와 대회·단계. 토너먼트에서 이기면 지움 |
| `mate` | 해가 넘어갈 때 | 그해 같은 팀·같은 군이었다(같은 포지션이었는지 포함) |

구현한 이야기 세 가지

1. **지난 맞대결 → 다음 맞대결**: 맞붙기 전 "지난 맞대결(3년차 5월)은 내가 졌다" / "이 상대에게 2연패 중". 맞붙은 뒤 "2연패를 끊었다" / "이 상대에게 3연패" / "3연승이 끊겼다".
2. **같은 팀 → 다른 팀에서 재회**: 맞붙기 전 "3년차까지 같은 팀이었다(같은 자리를 다퉜다). 이제는 상대다." 맞붙은 뒤 "3년차까지 같은 팀이던 상대와의 첫 재회에서 이겼다/졌다".
3. **토너먼트 탈락 → 설욕**: 맞붙기 전 "4년차 KGL 서머 플레이오프 준결승에서 이 팀에 졌다. 설욕할 기회." 토너먼트에서 이기면 "4년차 …의 패배를 갚았다." 그리고 다음 시즌 목표의 라이벌 후보 설명에 그 패배가 이유로 나옵니다.

- 문장이 여럿 해당하면 하나만: 토너먼트 패배 → 재회 → 첫 맞대결 → 연승·연패 순.
- 보이는 곳(모두 기존 자리의 한 줄): 홈의 "이번 달 라이벌전" 줄, 경기 준비 화면의 라이벌 줄, 경기 결과 화면의 라이벌 줄, 진행 요약의 라이벌전 줄.
- 일이 없는 달에는 아무것도 뜨지 않습니다(v0.11.4와 같음).
- **예전 저장**: 네 값이 없으므로 지난 일에 대한 문장은 나오지 않습니다. 통산 전적이 0승 0패일 때의 "첫 맞대결."만 예외입니다(기록으로 확인되는 사실). 이후의 맞대결부터 쌓입니다.
- 드문 조합은 억지로 만들지 않았습니다. 토너먼트에서 라이벌의 팀에 지는 일은 30커리어에 몇 번입니다.

## 4. 경기 선택의 설명

토너먼트 경기 결과 화면 맨 위에 **"내 선택 → 그때의 영향 → 실제 결과"** 를 두 줄 이내로 적습니다.

- 1줄: "**강하게 압박한다**을(를) 골랐다 → 세트 승률 평균 +1.3%p(+2 / −1 / +3) → 실제 2:1 승리." 숫자는 판정 때 실제로 들어간 세트별 보정입니다. 전략 없이 치렀으면 "보정 없음".
- 2줄: "승부처 「…」에서 **…** → 성공/실패." (있을 때만. 감독 판단으로 맡겼으면 표시)
- 단서: "선택은 확률을 조금 움직였을 뿐이다. 결과의 원인이라고 단정할 수는 없다."
- 예전에 같은 내용을 풀어 쓰던 줄("내 전략 — …", 승부처 목록)은 뺐습니다. 세트별 칩은 그대로입니다.
- 라이벌이 있던 경기면 맨 아래 라이벌 줄에 3절의 한 줄이 붙습니다.
- 정규 리그 경기는 월간 집계 그대로입니다. 개별 경기 장면을 만들지 않았습니다.

## 5. 돈의 선택 (P1, 작게)

새 상품은 없습니다. 기존 두 항목에 "언제 쓰면 의미가 있는가"를 붙였습니다.

### 전술 분석가 → 분석 자료 (승부를 위한 지출)

- 전술 분석가(월 350만)를 **직접 산 달**에, 내가 **주전으로 뛰는 토너먼트 시리즈**(플레이오프·국제전)에서 팀 전력 +1. 자동으로 샀다면 그달 경기가 끝난 뒤라 **다음 달**에 걸립니다.
- 리그 경기에는 들어가지 않습니다. 네이션스컵(국가대표)에도 들어가지 않습니다.
- 기존 효과(판단력 +0.3, 숙련 폭 +0.2)는 그대로입니다.
- 크기: 플레이오프 달 여섯 번의 비교에서 1세트 승률 평균 +1.3%p(능력치 몫 포함). 전략 하나의 효과(세트당 최대 약 ±6%p)보다 작습니다.
- **기회비용**: 팀이 플레이오프에 못 올라가면 그달의 분석 자료는 쓰이지 않습니다. 주전이 아니면 적용되지 않습니다. 토너먼트가 없는 달에는 능력치 몫만 남습니다. 자산 탭에서 이름을 누르면 "이번 달에는 플레이오프나 국제전이 열린다(팀이 올라가야 경기가 있다)" / "이번 달에는 토너먼트가 없어 분석 자료는 쓰이지 않는다"가 나옵니다.
- 적용된 경기에는 경기 준비 화면에 "분석 자료 · 전력 +1" 칩이, 결과 화면에 한 줄이 나옵니다.
- 사지 않으면 0이라 판정이 예전과 같습니다.

### 팬 미팅 → 인기가 지금 무엇을 바꾸는지 보여 주기 (미래를 위한 지출)

- 규칙은 바꾸지 않았습니다. 자산 탭에서 팬 미팅의 이름을 누르면 **지금 인기로 실제로 얼마가 달라지는지**가 나옵니다: "지금 인기 23: 방송 한 달 수입 약 214만, 1군 연봉 제안 +12%, 연봉 협상 성공률 +5%p." 숫자는 게임이 쓰는 식 그대로입니다(방송 수입 30 + 인기×8, 연봉 ×(1 + 인기/200), 협상 +인기×0.2).
- 이것은 **정보 표시**입니다. 새 선택지가 아닙니다.

## 6. 구현하지 않은 것

- 목표 달성의 보상(1절의 이유).
- 라이벌의 반응 대사(없는 말을 만들게 되어 넣지 않음), 관계 수치 변화의 표시.
- 구단 소개와 전략의 연결(소개는 분위기 글).
- "미래를 위한 지출"의 새 규칙. 정보 표시만 했습니다.
- 정규 리그 경기의 개별 장면, 팀 동료 로스터, 새 사건, 새 소리.
- 손목 삭제, 포지션 전향, 새 리그(요청서의 금지 항목).
