# 패치 노트 v0.11.7

홈 화면의 순서를 다듬은 작은 패치입니다. 새 콘텐츠는 없고, 저장과 경기 계산은 그대로입니다.

- **목표 칸이 보유 자금 바로 아래로 올라왔습니다.** 홈의 순서: 선수 상태 → 보유 자금 → 목표 → 이번 달 할 일 → 라이벌전(있는 달) → 지난 진행.
- 목표는 접힌 두 줄 요약(올해 목표 / 다음 목표)으로 보이고, 누르면 조건별 막대와 설명이 펼쳐집니다. 펼쳐 둔 상태는 달이 넘어가도 유지됩니다.
- 자동진행 중에도 목표 칸은 하나만 있고, 진척 숫자가 달마다 바뀝니다.
- 자동진행 중에 **이번 달 할 일**이나 **목표**를 누르면 자동진행이 멈추면서 바로 적용됩니다(전에는 멈추기만 해서 한 번 더 눌러야 했습니다).

실제 폰에서의 확인은 아직 하지 못했습니다.
