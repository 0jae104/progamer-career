| `tutorial_end` | 안내를 끝내거나 건너뛴 순간 | 끝냄/건너뜀 | 설치당 1회 |
| `season_end` | 시즌 결산 화면 | 연차, 소속(연습생·2군·1군) | 시즌당 1회 |
| `career_end` | 은퇴 화면 | 연차, 등급, 1군 데뷔 여부 | 커리어당 1회 |
| `session` | 하루에 처음 열었을 때 | 날짜, 처음 연 날로부터 며칠째인지 | 하루 1회 |

계산식

- 첫 시즌 완료율 = `season_end`(연차 1)를 보낸 설치 수 ÷ `career_start`(1번째 커리어)를 보낸 설치 수
- D1 / D7 재방문율 = 처음 연 날의 다음 날 / 7일째에 `session`을 보낸 설치 수 ÷ 그날 `first_open`을 보낸 설치 수
- 커리어 완주율 = `career_end` 수 ÷ `career_start` 수 (커리어 번호별로 따로)

이미 게임 안에 있는 값: 커리어 ID(`cid`), 완주한 커리어 수(`pg_ach_v1`의 `runs`), 진행 횟수(`stat.turns`). 이벤트를 붙일 자리는 `engine.js`의 `resolve`(구단 선택), `tutFinish`, `offseason`(시즌 결산), `retire`입니다. 판정은 게임 난수를 쓰지 않아야 합니다.

  3. 예전 주소는 바로 닫지 않고 안내와 백업 기능이 있는 채로 일정 기간 유지한다
  4. `https://0jae104.github.io/progamer-career/`에서 사용자 이름이나 저장소 이름을 바꾸는 것도 주소 변경입니다
