# 폰으로 한 경기 해 보기 (3분) + 재미 설문

v0.11.0의 "경기 한 판"이 재미있는지 사람이 확인하는 문서입니다. 기술 점검(`docs/phone-check-12.md`)과는 따로입니다.

**현재 상태(2026-11-21): 아직 아무도 실행하지 않았습니다.** 개발 환경에는 폰이 없고 배포 주소에 접속할 수 없습니다. 아래 표는 전부 비어 있습니다.

주소: https://0jae104.github.io/progamer-career/ (v0.11.0이 배포된 뒤. 타이틀 맨 아래 숫자가 `v0.11.0`인지 먼저 봅니다. 예전 숫자면 새로 고칩니다)

## 해 보는 방법 (3분)

1. 폰의 미디어 음량을 조금 올립니다(아이폰은 무음 스위치도 확인).
2. 주소를 열고 타이틀에서 **경기 체험하기**를 누릅니다. 하던 커리어와 기록은 건드리지 않습니다.
3. 경기 준비 화면을 읽습니다. 상대, 몇 선승인지, 내 컨디션, "전력으로 본 세트 승률"이 보입니다.
4. 전략 셋 가운데 하나를 고르고 **경기 시작**을 누릅니다.
5. 세트가 진행되는 것을 봅니다. 답답하면 "빠르게"나 "바로 결과"를 눌러도 됩니다.
6. 승부처가 나오면 하나를 고릅니다.
7. 결과 화면을 읽고 "다음으로"를 누릅니다. 이겼으면 다음 라운드가 이어집니다. 한 번 더 하고 싶은지 스스로 느껴 봅니다.
8. 끝나면 타이틀로 돌아옵니다. 다시 누르면 다른 선수·다른 대회로 시작합니다.

소리가 싫으면 창 오른쪽 위의 "소리 켜짐"을 누릅니다.

본편에서 보려면: 새 커리어로 1군 주전이 된 뒤 4월·8월(플레이오프), 5월(미드시즌 컵), 10월(월드 파이널)에 같은 화면이 나옵니다. 기록 탭의 "빠른 진행"이 켜져 있으면 전략을 묻지 않으니 끄고 합니다.

## 질문 네 가지

한 사람당 한 번, 해 본 직후에 묻습니다.

| # | 질문 | 답 |
|---|---|---|
| 1 | 경기 전에 무엇을 골랐고, 왜 골랐는지 설명할 수 있나? | 예 / 아니오 (+ 고른 전략과 이유 한 줄) |
| 2 | 내 선택이 결과에 영향을 줬다고 느꼈나? | 1(전혀) ~ 5(확실히) |
| 3 | 소리는 어땠나? | 좋음 / 보통 / 거슬림 / 무음이 낫다 (+ 이유) |
| 4 | 다음 경기를 바로 해 보고 싶은가? | 예 / 아니오 (+ 이유) |

## 옆에서 지켜볼 것 (가능하면)

| 관찰 | 적는 법 |
|---|---|
| 체험하기를 누른 뒤 첫 행동(전략 누르기)까지 걸린 시간 | 초 |
| 경기 시작부터 결과 화면까지 걸린 시간 | 초 |
| 헤맨 화면, 뜻 없이 누른 버튼 | 어느 화면, 몇 번 |
| "빠르게"나 "바로 결과"를 눌렀나 | 예 / 아니오, 몇 번째 세트에서 |
| 웃거나 놀라거나 긴장한 순간 | 어느 장면 |
| 지루해 보인 순간 | 어느 장면 |
| 결과 화면을 설명 없이 이해했나(전략의 +%p가 무슨 뜻인지) | 예 / 아니오 |
| 한 판 더 했나 | 몇 판 |

## 판단 기준 (처음 세운 가설)

업계 평균이 아니라 이 프로젝트가 처음 정한 기준입니다. 본인 + 가능하면 5명.

- 대부분이 1번에 "예"라고 답하고 고른 이유를 말할 수 있다.
- 절반 이상이 4번에 "예"라고 답한다.
- 2번의 평균이 3 이상이다.
- 3번에 "거슬림"이나 "무음이 낫다"가 절반을 넘지 않는다.

못 미치면 **기능을 더하지 않고** 못 미친 단계를 고칩니다. 1번이 낮으면 경기 준비 화면의 설명, 2번이 낮으면 전략의 크기와 결과 화면의 표시, 3번이 낮으면 소리, 4번이 낮으면 관전과 결과의 리듬입니다. 개발 쪽에서 미리 의심하는 곳은 `docs/stage11-match-fun-design.md` 9절에 있습니다.
