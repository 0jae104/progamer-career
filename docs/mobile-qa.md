## 따라 하는 순서 (한 번에 약 40분)

처음 하는 사람도 같은 순서로 할 수 있게 적었습니다. 괄호 안은 점검표 번호입니다.

**준비 (2분)**
1. 브라우저 설정에서 이 사이트의 데이터를 지웁니다. 크롬: 주소창 왼쪽 아이콘 → 사이트 설정 → 데이터 삭제. 삼성 인터넷: 설정 → 사이트 및 다운로드 → 사이트 데이터 관리. 사파리: 설정 앱 → Safari → 고급 → 웹 사이트 데이터.
2. 0절의 표에 기기와 버전을 적습니다.

**A. 첫 15분 (1절, 2절 앞부분)**
1. 주소를 열고 타이틀이 뜨는 시간을 봅니다(1-1, 1-2).
2. 새 커리어 → 아이디 칸을 눌러 키보드가 올라온 상태에서 화면을 밀어 "입단 테스트 보러 가기"까지 닿는지 봅니다(1-3, 1-3c).
3. 포지션 다섯 개를 차례로 눌러 설명이 펼쳐지는지 봅니다(1-3b). 하나를 고르고 시작합니다.
4. 구단을 고르고(1-4), 안내 1/3 → 2/3 → 첫 진행 → 3/3을 따라갑니다(1-5, 1-6).
5. 새로 고침 한 번 → 이어하기 → 안내가 다시 나오지 않는지 봅니다(1-7).
6. 화면 맨 위와 맨 아래가 기기 테두리에 가려지지 않는지 봅니다(1-8, 1-9).
7. 진행 버튼을 최대한 빠르게 두 번 눌러 한 달만 지나는지 봅니다(2-1). 창의 "확인"도 빠르게 두 번 눌러 봅니다(2-1b).

**B. 20~30분 연속 플레이 (2절)**
1. 기록 탭에서 "빠른 진행"을 켜지 말고 그대로 진행합니다. 2군, 1군을 거치며 이벤트·성장 카드·계약 제안을 봅니다(2-2, 2-3b).
2. 플레이오프에서 승부처 창이 뜨면 선택지 세 개가 겹치지 않는지, 맨 아래 "감독 판단에 맡긴다"까지 밀어서 닿는지 봅니다(2-3, 2-3c).
3. 중간에 한 번 다른 앱으로 갔다가 1분 뒤 돌아옵니다(2-8). 한 번은 브라우저를 완전히 닫았다가 다시 엽니다(2-9).
4. 한 번은 화면을 가로로 돌려 진행 버튼과 창의 버튼이 보이는지 봅니다(7-2, 7-2b).
5. 우승하면 연출과 "확인"을 봅니다(2-4). 우승이 나오지 않으면 그 칸은 비워 둡니다.
6. 발열과 끊김, 읽기 힘든 글자를 적습니다(2-10, 2-11).

**C. 은퇴와 기록 (3절, 4절)** — 은퇴까지 가기 어려우면 기록 탭에서 "빠른 진행"을 켜고 진행합니다.
1. 은퇴 화면 → 커리어 카드 만들기 → PNG 저장 → 저장된 위치를 찾아 적습니다(3-1 ~ 3-4).
2. 공유 버튼이 있으면 눌러 보고, 한 번은 공유 창을 그냥 닫습니다(3-5, 3-6).
3. 새 커리어를 누른 뒤 타이틀 → 기록실에서 방금 선수를 찾습니다(3-8, 4-1 ~ 4-4).

**D. 백업 (5절)**
1. 기록실 → 백업 → 내려받기 → 파일 위치를 찾아 적습니다(5-1).
2. "백업 파일 고르기"를 눌렀다가 아무것도 고르지 않고 닫습니다(5-2b). 다시 눌러 방금 파일을 고릅니다(5-2, 5-3).
3. 복원합니다(5-4). 가능하면 다른 브라우저에서도 복원합니다(5-5).
4. 사진 파일을 골라 거부되는지 봅니다(5-7).

**E. 홈 화면, 오프라인, 업데이트 (6절)**
1. 홈 화면에 추가 → 아이콘으로 열기 → 저장이 보이는지(6-1, 6-2).
2. 비행기 모드 → 열기 → 이어하기 → 한 달 진행(6-3, 6-4) → 비행기 모드 끄기(6-5).
3. 업데이트 항목(6-6, 6-7)은 새 버전이 배포된 날에만 확인할 수 있습니다. 그 전에는 비워 둡니다.

## 자동 검사로 이미 본 것 (참고)

PC 헤드리스 크롬에서 확인한 범위입니다(`node test/browser/run.js`). **실제 폰의 결과를 대신하지 않습니다.**

- 세로 320·360·390·430px과 가로 844×390·667×375에서 타이틀, 선수 등록(포지션 다섯 개), 장면 13종(이벤트·월간 보고·승부처·계약·우승 등), 탭 5개, 은퇴, 카드, 기록실 전체, 백업 미리보기와 오류: 가로 넘침, 44px 미만 버튼, 12px 미만 글자, 잘리거나 겹친 글자, 스크롤로 닿지 않거나 다른 것에 가려진 버튼, 이름 없는 버튼, 명암비
- 화면 높이를 330px로 줄인 상태(키보드가 올라온 상황 흉내)에서 아이디 입력과 버튼 닿기
- 진행 버튼과 선택지를 연달아 눌렀을 때 한 번만 받아들여지는지
- 처음 안내 3단계, 우승 연출과 동작 줄이기, 카드 PNG와 공유(흉내 낸 환경), 백업 내려받기·복원·거부, 서버 연결이 끊긴 상태에서의 실행, v0.6.0부터의 버전 갱신

자동 검사로 볼 수 없는 것: 노치·하단 바의 실제 여백, 실제 키보드가 화면을 미는 방식, 터치감과 오조작, iOS의 파일 저장 위치와 공유 창, 홈 화면 앱의 저장 분리, 오래 방문하지 않았을 때 저장이 지워지는지, 화면 읽기 음성, 실제 통신 환경의 로딩 시간, 발열, 가로·세로 회전 도중의 화면.

참고: 이 게임은 화면을 기기의 안전 영역 안에만 그립니다(`viewport-fit=cover`를 쓰지 않음). 그래서 노치가 화면을 가릴 가능성은 낮지만, 실제 기기에서 확인된 것은 아닙니다.
