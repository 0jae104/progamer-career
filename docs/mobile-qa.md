# 실제 폰 점검표

자동 검사는 PC의 헤드리스 크롬에서 화면 크기만 맞춰 돌린 것입니다. 아래 항목은 실제 폰에서 사람이 확인해야 합니다.

**현재 상태(v0.11.2 기준, 2026-11-21): 이 표에 기록된 실기기 확인 항목은 0개입니다.** 소유자가 자기 폰에서 플레이해 "정상 작동한다"고 알려 왔습니다(2026-11-21, 기기·브라우저·버전은 전달받지 못함). 다만 이 점검표의 항목별 결과는 받지 못했으므로 아래 표는 그대로 비워 둡니다. 세 브라우저 모두 미실행입니다. 확인한 칸에만 표시하세요. 이 문서를 만든 개발 환경(클라우드의 리눅스)에는 폰이 없고 배포 주소에도 접속할 수 없어, 아래 표는 소유자나 테스터가 직접 채워야 합니다.

| 브라우저 | 실행 여부 | 확인한 항목 수 | 마지막 확인 |
|---|---|---|---|
| 안드로이드 크롬 (A) | 미실행 | 0 / 66 | - |
| 삼성 인터넷 (S) | 미실행 | 0 / 66 | - |
| iOS 사파리 (I) | 미실행 | 0 / 66 | - |

대상 주소: https://0jae104.github.io/progamer-career/

표시 방법: `O` 통과, `X` 실패(맨 아래 양식으로 기록), `-` 해당 없음(그 기기에 없는 기능), **빈칸은 미실행**입니다. 빈칸을 통과로 읽지 않습니다. PC 브라우저의 "모바일 보기"(개발자 도구)로 본 것은 실기기 결과가 아니므로 이 표에 적지 않습니다.

## 시작하기 전에: 내 기록을 지키는 방법

점검 순서에는 "사이트 데이터 지우기"와 "복원"이 들어 있습니다. **평소에 이 게임을 하던 폰·브라우저에서 그대로 하면 내 커리어와 명예의 전당이 지워집니다.**

- 가장 안전한 방법: 평소에 이 게임을 열지 않는 브라우저에서 점검합니다(예: 평소 크롬으로 한다면 삼성 인터넷부터). 브라우저마다 저장이 따로입니다.
- 같은 브라우저로 해야 한다면 먼저 기록실 → 백업 → "백업 파일 내려받기"로 파일을 받고, 그 파일이 폰의 다운로드 폴더(아이폰은 파일 앱)에 실제로 있는지 열어 본 다음 시작합니다. 점검이 끝나면 기록실 → 백업에서 그 파일로 복원합니다.
- 시크릿(사생활 보호) 창은 점검에 쓰지 않습니다. 저장이 창을 닫으면 사라지고 홈 화면 추가·오프라인이 평소와 다르게 동작합니다.
- 다른 사람에게 점검을 부탁할 때도 이 안내를 먼저 전합니다.

## 따라 하는 순서 (한 번에 약 40분)

처음 하는 사람도 같은 순서로 할 수 있게 적었습니다. 괄호 안은 점검표 번호입니다.

**준비 (2분)**
1. **위 "시작하기 전에"를 먼저 읽습니다.** 그런 다음 브라우저 설정에서 이 사이트의 데이터를 지웁니다. 크롬: 주소창 왼쪽 아이콘 → 사이트 설정 → 데이터 삭제. 삼성 인터넷: 설정 → 사이트 및 다운로드 → 사이트 데이터 관리. 사파리: 설정 앱 → Safari → 고급 → 웹 사이트 데이터.
2. 0절의 표에 기기와 버전을 적습니다.

**A. 첫 15분 (1절, 2절 앞부분)**
1. 주소를 열고 타이틀이 뜨는 시간을 봅니다(1-1, 1-2).
2. 새 커리어 → 아이디 칸을 눌러 키보드가 올라온 상태에서 화면을 밀어 "입단 테스트 보러 가기"까지 닿는지 봅니다(1-3, 1-3c).
3. 포지션 다섯 개를 차례로 눌러 설명이 펼쳐지는지 봅니다(1-3b). 하나를 고르고 시작합니다.
4. 구단을 고르고(1-4), 안내 1/3 → 2/3 → 첫 진행 → 3/3을 따라갑니다(1-5, 1-6).
5. 새로 고침 한 번 → 이어하기 → 안내가 다시 나오지 않는지 봅니다(1-7).
6. 화면 맨 위와 맨 아래가 기기 테두리에 가려지지 않는지 봅니다(1-8, 1-9).
7. 진행 버튼을 최대한 빠르게 두 번 눌러 한 달만 지나는지 봅니다(2-1). 창의 "확인"도 빠르게 두 번 눌러 봅니다(2-1b).

**B. 20~30분 연속 플레이 (2절)**
1. 기록 탭의 "승부처·전략 맡기기"를 켜지 말고 그대로 진행합니다. 2군, 1군을 거치며 이벤트·성장 카드·계약 제안을 봅니다(2-2, 2-3b).
2. 플레이오프에서 승부처 창이 뜨면 선택지 세 개가 겹치지 않는지, 맨 아래 "감독 판단에 맡긴다"까지 밀어서 닿는지 봅니다(2-3, 2-3c).
3. 중간에 한 번 다른 앱으로 갔다가 1분 뒤 돌아옵니다(2-8). 한 번은 브라우저를 완전히 닫았다가 다시 엽니다(2-9).
4. 한 번은 화면을 가로로 돌려 진행 버튼과 창의 버튼이 보이는지 봅니다(7-2, 7-2b).
5. 우승하면 연출과 "확인"을 봅니다(2-4). 우승이 나오지 않으면 그 칸은 비워 둡니다.
6. 발열과 끊김, 읽기 힘든 글자를 적습니다(2-10, 2-11).

**C. 은퇴와 기록 (3절, 4절)** — 은퇴까지 가기 어려우면 맨 아래 "▶▶ 자동진행"으로 진행합니다.
1. 은퇴 화면 → 커리어 카드 만들기 → PNG 저장 → 저장된 위치를 찾아 적습니다(3-1 ~ 3-4).
2. 공유 버튼이 있으면 눌러 보고, 한 번은 공유 창을 그냥 닫습니다(3-5, 3-6).
3. 새 커리어를 누른 뒤 타이틀 → 기록실에서 방금 선수를 찾습니다(3-8, 4-1 ~ 4-4).

**D. 백업 (5절)**
1. 기록실 → 백업 → 내려받기 → 파일 위치를 찾아 적습니다(5-1).
2. "백업 파일 고르기"를 눌렀다가 아무것도 고르지 않고 닫습니다(5-2b). 다시 눌러 방금 파일을 고릅니다(5-2, 5-3).
3. 복원합니다(5-4). 가능하면 다른 브라우저에서도 복원합니다(5-5).
4. 사진 파일을 골라 거부되는지 봅니다(5-7).

**E. 홈 화면, 오프라인, 업데이트 (6절)**
1. 홈 화면에 추가 → 아이콘으로 열기 → 저장이 보이는지(6-1, 6-2).
2. 비행기 모드 → 열기 → 이어하기 → 한 달 진행(6-3, 6-4) → 비행기 모드 끄기(6-5).
3. 업데이트 항목(6-6, 6-7)은 새 버전이 배포된 날에만 확인할 수 있습니다. 그 전에는 비워 둡니다.

- 화면 높이를 330px로 줄인 상태(키보드가 올라온 상황 흉내)에서 아이디 입력과 버튼 닿기
- 진행 버튼과 선택지를 연달아 눌렀을 때 한 번만 받아들여지는지
- 탭 두 개로 같은 커리어를 열었을 때 오래된 탭이 멈추고 덮어쓰지 않는지, 파일 보관본을 지워도 저장이 남는지
- 처음 안내 3단계, 우승 연출과 동작 줄이기, 카드 PNG와 공유(흉내 낸 환경), 백업 내려받기·복원·거부, 서버 연결이 끊긴 상태에서의 실행, v0.6.0부터 v0.10.1까지의 버전 갱신

자동 검사로 볼 수 없는 것: 노치·하단 바의 실제 여백, 실제 키보드가 화면을 미는 방식, 터치감과 오조작, iOS의 파일 저장 위치와 공유 창, 홈 화면 앱의 저장 분리, 오래 방문하지 않았을 때 저장이 지워지는지, 화면 읽기 음성, 실제 통신 환경의 로딩 시간, 발열, 가로·세로 회전 도중의 화면.
