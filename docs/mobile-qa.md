# 실제 폰 점검표

자동 검사는 PC의 헤드리스 크롬에서 화면 크기만 맞춰 돌린 것입니다. 아래 항목은 실제 폰에서 사람이 확인해야 합니다. **이 문서의 항목은 아직 아무도 확인하지 않았습니다.** 확인한 칸에만 표시하세요.

대상: 안드로이드 크롬(A), 삼성 인터넷(S), iOS 사파리(I). 주소: https://0jae104.github.io/progamer-career/

표시 방법: 통과 `O`, 문제 `X`(아래 양식으로 기록), 해당 없음 `-`, 아직 안 봄은 빈칸.

## 0. 점검 전에

- 기기 이름, OS 버전, 브라우저 버전을 적어 둡니다.
- 타이틀 화면 맨 아래의 버전 숫자를 적어 둡니다(예: v0.8.0).
- 처음 상태에서 보려면 브라우저 설정에서 이 사이트의 데이터를 지우거나 시크릿 창을 씁니다. 단, 시크릿 창에서는 저장이 남지 않는 것이 정상입니다.

## 2. 길게 플레이 (약 250번 진행, 20~30분)

| # | 확인할 것 | A | S | I |
|---|---|---|---|---|
| 2-1 | 진행 버튼을 빠르게 연달아 눌러도 멈추거나 두 번 진행되지 않는다 | | | |
| 2-2 | 이벤트 선택지, 성장 카드, 계약 제안 버튼이 한 손으로 눌린다. 잘못 눌리는 버튼이 없다 | | | |
| 2-3 | 승부처 화면(플레이오프·국제전)의 선택지 3개와 확률이 겹치지 않고, 창 안에서 스크롤로 모두 닿는다 | | | |
| 2-3b | 계약 제안 화면에서 구단마다 전력·순위·감독 신뢰·라이벌 설명이 보이고, "계약" 버튼까지 스크롤로 닿는다 | | | |
| 2-4 | 우승하면 색종이 연출이 한 번 나오고, 바로 "확인"을 눌러 넘길 수 있다 | | | |
| 2-5 | 기기 설정에서 "동작 줄이기"를 켜면 색종이 없이 같은 내용이 나온다 | | | |
| 2-6 | 능력·리그·투자·기록 탭이 모두 열리고 가로로 밀리지 않는다 | | | |
| 2-7 | 월간 보고의 경기 목록에서 "준결승 vs 긴 구단 이름"이 잘리지 않는다 | | | |
| 2-8 | 앱을 다른 앱으로 전환했다 돌아와도 화면이 그대로다 | | | |
| 2-9 | 브라우저를 완전히 닫았다 다시 열면 "이어하기"로 같은 달에서 이어진다 | | | |
| 2-10 | 진행 중 기기가 뜨거워지거나 화면이 눈에 띄게 끊기지 않는다 | | | |
| 2-11 | 글자가 작아서 읽기 힘든 곳이 없다(있으면 어느 화면인지 기록) | | | |

## 3. 은퇴, 커리어 카드

| # | 확인할 것 | A | S | I |
|---|---|---|---|---|
| 3-1 | 은퇴 화면에 "명예의 전당에 기록했다"가 보인다 | | | |
| 3-2 | "커리어 카드 만들기" → 몇 초 안에 카드 그림이 보인다. 글꼴이 게임 화면과 같은 모양이다 | | | |
| 3-3 | "PNG 저장" → 파일이 어디에 저장됐는지 확인(다운로드 폴더, 사진 앱, 파일 앱 중 어디인지 기록) | | | |
| 3-4 | 저장된 그림을 열면 1080×1350이고 글자가 잘리지 않았다 | | | |
| 3-5 | "공유" 버튼이 보이는가(보이면 누르고, 공유 창에서 메신저를 골라 그림이 전달되는지) | | | |
| 3-6 | 공유 창을 그냥 닫으면 "공유를 취소했다"가 뜨고 게임은 그대로다 | | | |
| 3-7 | 버튼으로 저장이 안 되는 경우, 그림을 길게 눌러 "이미지 저장"이 되는가 | | | |
| 3-8 | "새 커리어"를 시작한 뒤에도 기록실 → 명예의 전당에 방금 선수가 남아 있다 | | | |

## 4. 기록실: 명예의 전당, 도전 과제

| # | 확인할 것 | A | S | I |
|---|---|---|---|---|
| 4-1 | 타이틀 "기록실"과 게임 안 기록 탭 양쪽에서 열린다 | | | |
| 4-2 | 점수순·우승순·최근 은퇴순이 바뀐다 | | | |
| 4-3 | "비교"를 두 명 누르면 비교 화면이 열리고 표가 가로로 넘치지 않는다 | | | |
| 4-4 | 삭제 → 확인 창 → 삭제 → "되돌리기"로 복구된다 | | | |
| 4-5 | 도전 과제를 달성하면 화면 위에 알림 한 줄이 뜨고 노치에 가려지지 않는다 | | | |

## 5. 백업과 복원

| # | 확인할 것 | A | S | I |
|---|---|---|---|---|
| 5-1 | 기록실 → 백업 → "백업 파일 내려받기" → JSON 파일이 어디에 저장됐는지 확인하고 위치 기록 | | | |
| 5-2 | "백업 파일 고르기"를 누르면 파일 선택 창이 열리고 방금 그 JSON을 고를 수 있다 | | | |
| 5-3 | 고르면 파일의 내용과 지금 기기의 내용이 나란히 보인다 | | | |
| 5-4 | "덮어쓰고 복원한다" → 타이틀에 "백업을 복원했다" → 이어하기로 같은 선수가 열린다 | | | |
| 5-5 | **다른 브라우저로 복원**: 크롬에서 받은 파일을 삼성 인터넷(또는 사파리)에서 복원해 같은 선수·명예의 전당이 보인다 | | | |
| 5-6 | 메신저나 메일로 자신에게 보낸 백업 파일을 다른 기기에서 받아 복원할 수 있다 | | | |
| 5-7 | 사진이나 다른 파일을 고르면 "백업 파일이 아니다"라고 나오고 데이터는 그대로다 | | | |

## 6. 홈 화면 추가, 오프라인, 업데이트

| # | 확인할 것 | A | S | I |
|---|---|---|---|---|
| 6-1 | 브라우저 메뉴의 "홈 화면에 추가"로 아이콘이 생긴다 | | | |
| 6-2 | 아이콘으로 열면 주소창 없이 열리고, 브라우저에서 하던 저장이 그대로 보인다 (**iOS는 홈 화면 앱과 사파리의 저장이 분리될 수 있음. 분리되면 X가 아니라 그 사실을 기록**) | | | |
| 6-3 | 비행기 모드에서 열어도 타이틀이 뜨고 "오프라인 상태다" 안내가 보인다 | | | |
| 6-4 | 비행기 모드에서 이어하기, 한 달 진행, 커리어 카드 생성이 된다 | | | |
| 6-5 | 비행기 모드를 끄고 다시 열면 정상이다 | | | |
| 6-6 | **업데이트**: 새 버전이 배포된 뒤 열면(한두 번 새로 고침) 타이틀 아래 버전 숫자가 바뀌고, 저장·명예의 전당·도전 과제가 그대로다 | | | |
| 6-7 | 업데이트 직후 "게임 파일을 다 받지 못했거나…" 안내가 뜨면, "새로 고침"으로 해결되는지 기록 | | | |
| 6-8 | 며칠 뒤 다시 열어도 저장이 남아 있다 (**iOS 사파리는 오래 방문하지 않은 사이트의 저장을 지울 수 있음. 지워졌으면 며칠 만이었는지 기록**) | | | |

## 7. 화면 크기와 접근성

| # | 확인할 것 | A | S | I |
|---|---|---|---|---|
| 7-1 | 작은 폰(가로 320~360px)에서 가로 스크롤이 생기지 않는다 | | | |
| 7-2 | 태블릿 또는 가로 모드에서 가운데 정렬로 보이고 깨지지 않는다 | | | |
| 7-3 | 기기의 글자 크기를 "크게"로 올려도 버튼 글자가 버튼 밖으로 나가지 않는다 | | | |
| 7-4 | 화면 읽기(톡백/보이스오버)를 켜고 타이틀 → 새 커리어 → 진행까지 읽는 순서가 화면 순서와 같다 | | | |
| 7-5 | 화면 읽기에서 장면 창이 열리면 창 안의 내용부터 읽고, 뒤 화면으로 빠져나가지 않는다 | | | |
| 7-6 | 블루투스 키보드가 있으면 Tab으로 이동할 때 초점 테두리가 보이고 Enter로 눌린다 | | | |
| 7-7 | 다크 모드·라이트 모드 설정과 무관하게 같은 어두운 화면으로 보인다 | | | |

## 자동 검사로 이미 본 것 (참고)

PC 헤드리스 크롬에서 확인한 범위입니다. 실제 폰의 결과를 대신하지 않습니다.

- 320×568, 390×844, 768×1024, 1280×800에서 250번 진행하며 가로 넘침, 44px 미만 버튼, 12px 미만 글자, 잘린 글자가 없는지
- 처음 안내 3단계의 위치와 새로 고침 뒤 유지, 우승 연출과 동작 줄이기
- 카드 PNG의 크기와 내려받기, 공유(흉내 낸 환경), 명예의 전당 조작, 백업 내려받기·복원·거부
- 서버 연결이 끊긴 상태에서의 실행, 버전 갱신 뒤 저장 유지

자동 검사로 볼 수 없는 것: 노치·하단 바, 실제 터치감, iOS의 파일 저장 위치와 공유 창, 홈 화면 앱의 저장 분리, 화면 읽기 음성, 실제 통신 환경에서의 로딩 시간, 발열.
