## 6. 전후 비교

| | v0.10.2 | v0.11.0 |
|---|---|---|
| 토너먼트 시리즈에서 뜨는 창(승부처가 마지막 세트에 나온 경우) | 승부처 → 승부처 결과 (창이 두 번 올라옴). 그 뒤 월간 보고 | 경기 준비 → 관전 → 승부처 → 승부처 결과 → 경기 결과가 **한 창 안에서** 이어짐(창은 한 번 올라옴). 그 뒤 월간 보고 |
| 같은 경우의 누름 횟수 | 2번(선택, 확인) | 5번(전략, 시작, 선택, 확인, 다음). 전략 없이 시작하면 4번 |
| 승부처가 없던 시리즈(2:0 등) | 창 없음. 월간 보고의 한 줄 | 경기 준비 → 관전 → 경기 결과. 3번 누름(전략 없이 2번) |
| 시리즈 하나에 걸리는 시간(읽는 시간 제외) | 0초 | 관전 3~5초(3전제), 5전제는 길어야 약 7초. "빠르게"는 3분의 1, "바로 결과"는 0초 |
| 결과에서 내 선택의 영향이 보이는가 | 승부처의 성공·실패와 그 세트의 전력 변화 | + 전략 이름, 세트마다 전략이 승률을 몇 %p 바꿨는지, 유리·불리하게 작용한 세트 수와 그 승패 |
| 소리 | 없음 | 효과음 10종. 타이틀·기록 탭·경기 창에서 한 번 누르면 꺼짐 |
| 건너뛰기 | 해당 없음 | 관전 중 언제든. 결과는 같음(검사로 확인) |
| 빠른 진행을 쓰는 사람 | 승부처 자동 | 그대로(전략도 묻지 않음. 판정은 v0.10.2와 같음) |
| 3분 안에 경기를 해 볼 방법 | 없음 | 타이틀의 "경기 체험하기" |

누름 횟수는 늘었습니다. 줄인 것은 "창이 닫혔다가 다시 뜨는 횟수"와 "아무 정보 없이 지나가던 시리즈"입니다. 늘어난 누름이 재미인지 번거로움인지는 사람이 판단할 부분입니다.

## 7. 결론

- 지금 버전은 **소유자가 폰으로 3분 안에 해 볼 수 있는 상태**입니다(병합·배포 뒤 타이틀의 "경기 체험하기"). 다만 그 폰에서 실제로 잘 보이고 잘 들리는지는 확인되지 않았습니다.
- 재미가 아직 부족할 것으로 의심하는 곳은 `docs/stage11-match-fun-design.md` 9절에 적었습니다. 가장 큰 것은 **관전이 세트 스코어뿐이라는 점**과 **전략의 영향이 한 판에서는 작게 느껴질 수 있다는 점**입니다.
