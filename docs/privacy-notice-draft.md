# 개인정보 안내문 초안

**검토용 초안입니다. 게임 화면에는 넣지 않았습니다.** `docs/release-checklist.md` 4절에서 코드로 확인한 사실만 적었습니다. 법적으로 충분한지, 어떤 형식(개인정보 처리방침)이 필요한지는 전문가가 판단해야 합니다. 분석·광고 도구를 붙이면 이 문서는 다시 써야 합니다.

기준: v0.11.0

---

## 이 게임이 저장하는 것

- 게임 진행 상황, 은퇴한 선수의 기록(명예의 전당), 도전 과제 달성 여부, 처음 안내를 봤는지 여부, 소리를 켰는지 껐는지
- 선수 아이디(직접 입력한 10자 이내의 글자)

이것들은 **지금 쓰는 기기의 브라우저 안에만** 저장됩니다. 게임을 만든 사람에게 전송되지 않으며, 만든 사람은 볼 수 없습니다. 회원 가입, 로그인, 광고, 이용 분석 도구는 없습니다.

## 저장이 사라지는 경우

- 브라우저의 사이트 데이터(방문 기록·쿠키 등)를 지웠을 때
- 시크릿(사생활 보호) 창으로 열었을 때(창을 닫으면 사라집니다)
- 다른 기기나 다른 브라우저에서 열었을 때(그쪽에는 저장이 없습니다)
- 일부 브라우저는 오랫동안 방문하지 않은 사이트의 저장을 스스로 지웁니다

기록을 지키거나 옮기려면 기록실 → 백업에서 백업 파일을 내려받아 두세요.

## 기기 밖으로 나가는 것

- **직접 내보낼 때만**: 백업 파일을 내려받거나, 커리어 카드 그림을 저장·공유할 때. 그 파일을 어디에 보관하고 누구에게 보낼지는 본인이 정합니다. 커리어 카드에는 선수 아이디가 들어가므로 아이디에 실명이나 연락처를 쓰지 마세요.
- **게임 파일을 받을 때**: 이 게임은 GitHub Pages에서 제공됩니다. 페이지를 열면 여느 웹사이트처럼 접속 정보(IP 주소 등)가 호스팅 업체(GitHub)에 전달됩니다. 게임을 만든 사람은 그 기록을 받아 보지 않습니다.
- **글꼴을 받을 때**: 화면 글꼴을 Google Fonts에서 받습니다. 이때 브라우저가 Google 서버에 접속합니다(IP 주소 전달). 오프라인에서는 기기의 기본 글꼴로 보입니다.
