# 패치 노트 v0.11.9

성장이 눈에 보이게 하고, 번 돈에 쓸 곳을 하나 만든 업데이트입니다. 저장은 그대로 이어집니다.

**성장이 보입니다**
- 한 달을 진행하면 가장 크게 변한 능력치와 함께 **OVR 칩**이 나옵니다: `OVR 65 → 66`, 또는 `OVR 65 · 다음까지 0.4`.
- 능력치가 거의 오르지 않은 달에는 **이유**가 한 줄 붙습니다: 쉬어서, 주요 능력치가 한계에 가까워서, 나이 때문에, 고른 할 일이 포지션과 맞지 않아서.
- 자동진행 중에는 진행 줄에 방금 넘긴 달의 성장이 한 토막으로 나옵니다.
- 목표 칸에 남은 조건이 숫자로 보입니다(예: "OVR 3 부족"). 폭이 좁은 폰에서는 목표를 펼치면 보입니다.

**돈의 쓸모**
- **시즌 프로젝트**(자산 탭, 한 시즌에 하나, 선택): 
  - 집중 캠프 — 포지션의 주요 능력치 두 개의 **한계 +1**. 값은 연봉의 10%, 컨디션 −20.
  - 팬 캠페인 — **인기 +8 안팎**. 값은 연봉의 6%, 컨디션 −12.
  - 고르지 않아도 됩니다. 자동으로 사지 않고, 자동진행을 멈추지도 않습니다.
- 자동 관리를 켜면 `월급 − 반복 지출`이 한 줄로 보이고, 지출이 월급보다 크면 알려 줍니다.
- 장비·코치·식단의 설명에 "지금 효과 → 다음 단계"가 나옵니다. 능력치가 한계에 가까워 사도 효과가 거의 없을 때는 그렇게 적습니다.

**노력형**
- 한계가 조금 더 낮게 시작해(−1 → −2) 25세까지 시즌마다 더 많이 오릅니다(+0.3 → +0.7). 20대 초반에 성장이 막히던 달이 줄고, 22~25세에 더 자랍니다. 진행 중인 노력형 커리어는 다음 시즌부터 새 폭으로 오릅니다.
- 천재형과 두뇌형의 숫자는 바꾸지 않았습니다.

실제 폰에서의 확인과 "재미있어졌는가"에 대한 사람의 평가는 아직 받지 못했습니다.
