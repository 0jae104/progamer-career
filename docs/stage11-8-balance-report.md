# 11.8 밸런스 보고서: 지출 정책 비교 (v0.11.12)

작성 2026-11-23. 기준은 v0.11.11(`811ebe3`). 로그는 `docs/qa-logs/stage11-8/`.

**읽기 전에**
- 모두 자동 규칙(`autoStep`)에 정책만 얹은 시뮬레이션입니다. 사람의 플레이와 다르고, 재미의 증거가 아닙니다.
- 표본: 시드 1·2 × 정책별 300커리어 = **정책마다 600커리어**(세 성향·다섯 포지션·네 리그 고르게, 정책끼리 같은 시드).
- 값은 평균±95% 신뢰구간. 구간이 겹치면 "차이가 있다"고 말할 수 없습니다.
- 명령: `node test/balance.js spend 300 --seeds=1,2`, `node test/balance.js econ 300 --seeds=1,2`, `node test/balance.js proj 300 --seeds=1,2`

## 2. 정책 10가지

- **사지 않음 / 집중 캠프 / 팬 캠페인 / 단계형만**: 기존 정책(매 시즌 또는 돈이 되는 대로).
- **강팀 고르기**: 에이전트 없이, 제안 가운데 전력이 가장 강한 1군 팀과 계약. **강팀+에이전트**: 계약이 끝나는 해에 에이전트를 사고 같은 규칙. → 이 둘이 짝입니다.
- **고국 복귀**: 에이전트 없이, 해외에서 뛸 때 고국 1군 제안이 보이면 받음. **복귀+에이전트**: 해외에서 뛰는 동안 에이전트를 사 두고 같은 규칙. → 이 둘이 짝입니다.
- **아카데미**: 돈이 되면 아카데미(그 시즌에는 다른 프로젝트 없음).

## 3. 읽은 것

**전담 에이전트 (강팀 고르기 ↔ 강팀+에이전트)**
- 커리어당 3.5번 사고 3.1억을 씁니다(통산 수입의 6.1%). 그 가운데 2.46번의 시장에서 후보를 더 가져왔고, 0.67번은 그 팀과 계약했습니다.
- 1군 우승 2.55±0.35 → 3.14±0.40, 승률 39.7±1.5 → 41.0±1.5%, 커리어 점수 40.3±1.9 → 41.6±1.9. **방향은 일관되지만 신뢰구간이 겹칩니다.** 통산 수입은 54억 → 52억으로 줄었습니다(강팀은 연봉이 낮고, 에이전트 값도 냅니다).
- 최고 OVR·1군 경기·커리어 길이·이적 횟수는 같습니다.
- 정리: 에이전트는 능력을 올리지 않고, **돈을 조금 덜 벌고 우승 기회를 조금 더 얻는** 쪽으로 움직입니다. 집중 캠프(점수 +3.5)나 단계형 투자(+5.7)보다 작습니다. 과하지 않습니다.

**전담 에이전트 (고국 복귀 ↔ 복귀+에이전트)**
- 해외에서 뛴 커리어 가운데 고국 1군으로 돌아간 비율 82.5±4.3% → 86.5±3.9%. 차이는 구간 안입니다. 기존 `homeSlot`이 이미 대부분을 해결하고 있어, 에이전트가 더하는 것은 작습니다(커리어당 0.12번).
- 성적 지표는 같습니다.

**유소년 아카데미 (사지 않음 ↔ 아카데미)**
- 커리어당 2.1단계, 22억(통산 수입의 37.8%). 1단계 이상 91%, 3단계 46%. 은퇴 잔액의 중앙값 33억 → 12억(하위 10%는 4.0억 → 1.5억, 상위 10%는 144억 → 113억).
- 최고 OVR 78.9 → 79.0, 1군 경기 210±9 → 214±9, 승률 37.7 → 37.9%, 우승 2.15 → 2.11, 커리어 점수 39.1 → 39.4. **성적에는 차이가 없습니다.** 감독 신뢰 +1~3은 결과를 움직이지 않는 크기입니다.
- 배출한 프로는 평균 21명입니다.

**기존 프로젝트는 여전히 쓸모가 있는가**
- 집중 캠프: 최고 OVR 78.9 → 80.8, 점수 +3.5. 팬 캠페인: 최고 인기 43 → 83, 점수 +3.4. 단계형 투자: 승률 +3.6%p, 점수 +5.7. **성적을 올리는 것은 여전히 이 셋입니다.** 새 둘은 성적이 아닌 것을 삽니다.

**한 가지 최적 패턴이 생겼는가**
- "섞어 쓰기"가 점수는 가장 높지만(49.4), 이는 단계형 투자와 집중 캠프의 효과이고 에이전트·아카데미가 더한 것이 아닙니다(아카데미 단독 39.4, 에이전트 짝 +1.3).
- 성향별 순서(노력형 > 두뇌형 > 천재형)는 모든 정책에서 같습니다. 새 항목이 성향 사이의 차이를 넓히거나 뒤집지 않았습니다.
- 한 시즌에 하나만 고를 수 있으므로, 아카데미를 세우는 해에는 캠프를 못 합니다. 아카데미만 하는 정책은 캠프만 하는 정책보다 점수가 3.2 낮습니다. **기회비용이 실제로 있습니다.**

**돈**
- 잔고가 음수였던 걸음 0, 장부가 끊긴 커리어 0(정책 10 × 600커리어).
- 아카데미를 끝까지 해도 은퇴 잔액이 0에 가까워지지 않습니다(중앙값 12억).

## 5. 한계

- 600커리어는 우승 수처럼 편차가 큰 지표에서 ±0.3~0.4의 구간을 남깁니다. 에이전트의 우승 +0.59는 "있을 법하지만 확정은 아닌" 크기입니다.
- 정책은 단순한 규칙입니다("강팀이면 무조건", "돈이 되면 무조건"). 사람은 상황을 보고 고르므로 결과가 다를 것입니다.
- "고민하게 되는가"는 이 표의 어디에도 없습니다. 사람이 해 봐야 압니다.
