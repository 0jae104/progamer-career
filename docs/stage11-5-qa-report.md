## 3. 숫자

### 경기 결과가 달라졌나

- **분석 자료를 사지 않으면 같습니다.** 시즌 목표, 구단 소개, 라이벌 문장은 판정과 난수에 들어가지 않습니다. 400커리어 해시와 `sim.js 3000`의 통계(시드 1·2)가 v0.11.4와 같습니다. 달라진 줄은 버전과 소요 시간, 그리고 "변형 백업 1000개 중 거부된 수"(532 vs 526, 523 vs 538)입니다. 마지막 것은 저장 내용이 달라져(결산 장면에 목표 후보가 실림) 무작위로 망가뜨리는 위치가 달라진 것이고, 두 버전 모두 통과한 백업에서 오류 0입니다.
- **분석 자료를 사면 달라집니다.** 전술 분석가를 직접 산 달의 토너먼트에서 주전이면 팀 전력 +1. 플레이오프 달 6번의 비교에서 1세트 승률 평균 +1.3%p(같은 구매의 능력치 몫 포함). 자동 규칙의 시뮬레이션은 이 상품을 직접 사지 않으므로 위의 통계에는 나타나지 않습니다. 커리어 전체의 우승 수가 얼마나 달라지는지는 **재지 않았습니다**.

### 목표 달성률 (60커리어, 시드 1, 후보를 돌아가며 고른 경우)

| 목표 | 횟수 | 달성 | 미달성 | 판정 없음 |
|---|---|---|---|---|
| 2군 콜업 | 145 | 48% | 76 | 0 |
| OVR n 도달 | 242 | 60% | 97 | 0 |
| 1군 무대에 서기 | 200 | 23% | 155 | 0 |
| 1군 14경기 이상 출전 | 51 | 80% | 10 | 0 |
| 플레이오프 진출 | 152 | 27% | 111 | 0 |
| 플레이오프 시리즈 승리 | 66 | 36% | 42 | 0 |
| 1군 대회 우승 | 78 | 47% | 41 | 0 |
| 1군 평균 평점 | 225 | 29% | 148 | 11 |
| 라이벌에게 우세 | 138 | 53% | 45 | 20 |

- 자동 규칙으로 돌린 값이라 사람이 하면 다를 수 있습니다.
- "1군 무대에 서기" 23%, "플레이오프 진출" 27%, "평점" 29%는 낮습니다. 실패가 잦으면 재도전의 동기가 될지 좌절이 될지는 사람에게 물어야 합니다. 이번에는 조정하지 않았습니다.
- 라이벌 목표의 14%는 판정 없음(그해 맞붙지 않음)입니다.

### 라이벌 문장이 얼마나 나오나 (같은 표본)

- 맞대결 1,699번 중 맞붙은 뒤의 한 줄이 붙은 것 716번(42%).
- 종류: n연패 314, 연승이 끊김 130, 연패를 끊음 108, 재회에서 이김 88, 재회에서 짐 73, 토너먼트 패배를 갚음 3.
- **토너먼트 설욕은 드뭅니다**: 진 기록 14번, 갚은 것 3번(60커리어). 대부분의 플레이어는 한 커리어에서 보지 못합니다.
- 맞붙은 뒤의 "첫 맞대결을 이겼다/내줬다"는 이 표본에서 **한 번도 나오지 않았습니다**. 라이벌은 이미 전적이 있는 상태로 생기기 때문으로 보입니다. 죽은 문장일 가능성이 있고, 원인은 더 보지 않았습니다.
- "이 상대에게 n연패"가 가장 흔합니다. 같은 문장이 자주 보이면 금방 익숙해질 수 있습니다.

## 6. 진행 중에 나온 실패와 수정

- `sim.js`: 예전 저장을 열지 못함 → 라이벌 목록이 없는 저장에서 새 정리 코드가 멈춤. 목록이 있을 때만 돌도록 수정.
- `story.js`: "같은 팀이었다"가 승격 뒤의 소속으로 적힘 → 그 시즌에 실제로 뛴 소속으로 수정. 재회 문장이 다른 문장에 가려 한 번도 안 나옴 → 순서 수정. (검사 쪽의 잘못 두 건도 고침: 첫해 기본 목표를 세지 않음, 한 달에 두 번 맞붙을 때의 대조 시점.)
- 화면 검사: 320×568 홈이 13px, 360×800 라이벌전 달이 22px 넘침 → 그때는 "다음 목표" 제목 줄을 접음.
- `extras.js`: 전력 차가 큰 대진에서는 분석 자료의 +1이 표시 숫자(정수 %)를 바꾸지 못함 → 검사가 "줄지 않는다 + 한 번 이상 오른다"를 보도록 함. 규칙은 그대로이고, **이런 대진에서는 산 효과가 눈에 보이지 않습니다**.
