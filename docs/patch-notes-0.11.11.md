# 패치 노트 v0.11.11

큰 경기가 큰 경기처럼 보이고, 한 시즌이 이야기로 남도록 고친 업데이트입니다. 저장은 그대로 이어집니다.

**큰 경기**
- 결승·국제전·국가대표·라이벌전의 경기 준비 화면에 꼬리표와 **이 경기에 걸린 것**이 한 줄로 나옵니다. 예: "이기면 1군 리그 첫 우승이다", "이기면 통산 3번째 세계 대회 우승이다".
- 결과 화면의 제목이 경기의 모양을 말합니다: **역전승**(상대가 먼저 매치 포인트를 잡았는데 이긴 경기), 접전 끝 승리, 완승, 석패.
- 결승 승리·역전승·라이벌전 승리는 금색으로 한 번 반짝입니다. 기다릴 필요 없이 바로 넘어갈 수 있습니다.
- 평범한 경기는 전과 같습니다.

**순간의 소리**
- 역전승, 우승 알림, 콜업, 이적 확정, 수상, OVR이 오른 달, 시즌 결산, 나쁜 소식에 짧은 소리가 하나씩 납니다.
- 소리 버튼으로 끌 수 있고, 자동진행이 달리는 동안에는 나지 않습니다.
- 이적이 확정되면 화면 위쪽에 한 줄 알림이 3초 동안 뜹니다(누르면 닫힘).

**시즌 결산**
- 맨 위에 **그해에 있었던 일**이 세 문장까지 나옵니다. 예: "철판다 클럽으로 옮겨 맞은 첫 시즌이었다." / "8월, 결승에서 홍련 게이밍을 3-2로 꺾고 CGL 서머 우승을 차지했다." / "OVR이 85에서 88로 올랐다."
- 아래에는 다음 시즌에 대한 한 줄이 붙습니다(계약이 끝났는지, 몇 년 남았는지 등).
- 경기·승·평균 평점 세 칸은 칩 하나로 줄였습니다.

**사건**
- 같은 사건이 금방 다시 나오는 일이 줄었습니다. 사건이 나오는 횟수는 그대로입니다.
- 자주 나오던 일곱 사건은 두 번째부터 다른 글로 나옵니다. 선택지와 효과는 같습니다.

실제 폰에서의 확인과 "다음 시즌이 궁금해졌는가"에 대한 사람의 평가는 아직 받지 못했습니다. 소리가 어울리는지도 사람이 들어 본 적이 없습니다.
