# 11.4단계 결과: 홈의 상태 · 자산의 스크롤 · 라이벌 (v0.11.4)

작성 2026-11-21. 대상 v0.11.3(`0031727`) → v0.11.4.

실제 모바일 사용자의 네 가지: ① 홈에서 컨디션·손목·코치 평가(감독 신뢰)·인기를 한눈에 ② 자산 탭의 스크롤이 너무 길다 ③ 자금을 누르면 자산으로 ④ 라이벌을 일부러 찾아보지 않게 된다.

**먼저 한계부터.** 아래 숫자와 그림은 모두 PC 헤드리스 크롬의 폰 크기 에뮬레이션입니다. 실제 폰에서는 한 번도 실행하지 않았고, 사람이 "덜 답답하다"고 느끼는지는 확인하지 못했습니다(미검증).

## 1. 홈: 상태 네 칸과 자금 줄

- 선수 이름 줄 아래에 **컨디션 / 손목 / 코치 평가(입단 뒤에는 감독 신뢰) / 인기**를 2×2로 둡니다. 막대는 쓰지 않고 이름과 큰 숫자만 둡니다. 막대 네 개는 선수 탭에 그대로 있습니다.
- 값은 저장된 수치 그대로입니다(`S.cond`, `S.wrist`, `S.trust`, `S.fame`의 반올림). 붙는 말은 게임이 실제로 쓰는 기준에서만 나옵니다: 컨디션 40 미만 "낮음"(빨강)·70 이상 "좋음"(초록), 손목 35 이하 "주의", 부상 중 "재활 n개월". 변화 방향은 기록이 없어 "상승" 같은 말을 쓰지 않습니다. 감독 신뢰와 인기에는 아무 말도 붙이지 않습니다.
- 손목이 위험하거나 부상일 때 따로 뜨던 경고 칸은 없앴습니다. 손목 칸 하나가 빨갛게 바뀝니다(한 번만 강조).
- 그 아래 **보유 자금** 줄은 버튼입니다. 누르면 자산 탭 맨 위로 가고 아래 탭의 선택 표시도 바뀝니다. 확인 창은 없습니다. 기존 탭 이동(`data-act="tab" data-id="money"`)을 그대로 씁니다. 화면 읽기 이름은 "보유 자금 1억 1,790만, 자산 페이지 열기"입니다.
- 자동진행 중에 누르면 기존 규칙대로 먼저 멈춘 뒤 자산 탭으로 갑니다(멈춘 이유 "멈춤을 눌러 멈췄다", 저장된 달 = 화면의 달).
- 상태 요약은 **플레이 탭에만** 둡니다. 리그·자산·기록 탭에서는 이름 줄만 남겨 그 탭의 내용에 자리를 줍니다.
- 칸은 배열 하나에서 그립니다. 나중에 손목을 빼면 세 칸이 되고 마지막 칸이 한 줄을 채웁니다. 손목·부상의 엔진과 저장은 건드리지 않았습니다.
- **320px 폭(또는 높이 600px 이하)**에서는 2×2 대신 **한 줄 네 칸**으로 세우고 "이번 달 할 일" 제목 줄을 접습니다. 2×2로 두면 320×568에서 다음 목표가 42px 가려졌기 때문입니다. 이 폭에서는 "낮음·주의" 글자 대신 색으로만 표시됩니다.

## 2. 자산 탭

### 2-1. 순서

1. 보유 자금(큰 숫자) · 연봉 · 계약 — 한 줄
2. "자동 n개 켜짐 · 매달 자동으로 나가는 돈 X" — 한 줄
3. 남겨 둘 돈 / 한 달 자동 지출 상한 — 버튼 두 개(기존 그대로)
4. **매달 반복**(손목 물리치료, 심리 상담, 팬 미팅, 전술 분석가) — 펼쳐 있음
5. **단계형 투자**(장비 세팅, 개인 코치, 식단·수면 관리) — 접혀 있음. 접힌 줄에 "장비 0/5 · 코치 0/5 · 식단 0/5 · 자동 n개"가 보이고 누르면 펼쳐짐
6. 규칙 설명 한 문단(맨 아래)

항목은 한 줄입니다: **이름과 상태**(가격·"이번 달 완료"·"2/5 단계 · 다음 600만"·"5/5 최대") / **자동 켜짐·꺼짐** / **사기**. 긴 설명은 이름을 눌렀을 때만 그 아래에 펼쳐집니다.

- 가격, 조건, 효과, 자동 관리의 규칙(남겨 둘 돈, 상한, 건너뛴 이유)은 그대로입니다. 새 항목은 없습니다. 손목 물리치료도 그대로 있습니다.
- 접힘·펼침과 "어느 설명이 열려 있는가"는 화면 상태로만 기억합니다. 다른 항목을 켜거나 사도 닫히지 않습니다. 저장에는 들어가지 않습니다(새로 고치면 처음 상태).
- 안쪽에 따로 스크롤되는 영역은 만들지 않았습니다.

## 3. 라이벌

원칙: 새 창·새 메뉴·새 사건을 만들지 않고, 엔진이 이미 사실로 기록한 것만, 일이 있을 때만 보여 줍니다.

- **이번 달에 라이벌전이 있으면** 홈의 다음 목표 위에 한 줄이 뜹니다: "이번 달 라이벌전 — Taety의 솔트앤스틸 · 통산 0승 0패 · 기록 ›". 상대·소속·전적은 `G.rivalFixtures()`가 돌려준 값 그대로입니다. 누르면 리그 탭의 라이벌 기록 위치로 갑니다.
- **라이벌전이 없는 달에는 아무것도 뜨지 않습니다.** 빈 칸도 없습니다.
- **진행한 뒤의 요약**: 라이벌전 결과 줄에 지금의 통산 전적을 붙였습니다("라이벌전 Taety의 솔트앤스틸에 승리 · 통산 1승 0패"). 그리고 진행한 달에 소식 목록에 남은 라이벌의 일(콜업, 이적, 부상과 복귀, 우승, 부진, 은퇴, 대회에서의 맞대결)을 **최대 두 줄** 보여 줍니다. 문장은 엔진이 쓴 소식 그대로이고 새로 지어낸 것은 없습니다(검사가 요약의 문장이 소식 목록에 있는지 대조합니다). 라이벌 줄이 하나라도 있으면 "라이벌 기록 보기 ›"가 붙습니다.
- 자동진행은 예전처럼 라이벌 팀과의 토너먼트 경기에서 멈추고, 경기 준비 창에는 라이벌 이름과 통산 전적이 나옵니다(v0.11.2부터 있던 동작).
- 리그 탭의 라이벌 카드와 "함께한 기록"은 그대로입니다.

하지 않은 것: 관계(경쟁심·존중) 변화의 표시. 요약 시점에 "이번 진행으로 얼마나 바뀌었는지"가 기록에 없어 넣지 않았습니다. 재회·복귀 같은 일도 엔진이 소식으로 남긴 경우에만 나옵니다.

### 폰으로 2분 확인 (v0.11.4)

타이틀 맨 아래 숫자가 `v0.11.4`인지 먼저 봅니다.

1. 홈을 열면 스크롤 없이 컨디션·손목·감독 신뢰(연습생은 코치 평가)·인기 네 숫자와 보유 자금, 할 일 다섯 칸, 진행 버튼이 보이는가
2. 보유 자금 줄을 누르면 자산 탭 맨 위로 가는가. 아래 "플레이" 탭으로 돌아올 수 있는가
3. 자산 탭에서 거의 스크롤하지 않고 "심리 상담"의 자동을 켤 수 있는가. 위쪽의 "자동 1개 켜짐 · 매달 나가는 돈 220만"이 바뀌는가
4. "단계형 투자"를 눌러 펼친 뒤 하나를 사거나 켜도 닫히지 않는가. 이름을 누르면 설명이 나오는가
5. 자동진행 중에 보유 자금을 누르면 멈추고 자산 탭으로 가는가
6. (1군에서) 라이벌전이 있는 달에 홈에 "이번 달 라이벌전" 줄이 뜨고, 누르면 라이벌 기록으로 가는가. 그 달을 진행하면 요약에 결과와 통산 전적이 나오는가
7. 글자가 잘리거나 가로로 밀리는 곳, 잘못 누르기 쉬운 버튼이 없는가(특히 자산 탭의 "자동"과 "사기"가 붙어 있는 것)

```
폰과 브라우저:
1 홈 한 화면:            O / X
2 자금 → 자산:           O / X
3 자동 켜기(스크롤):     O / X   (스크롤했나:   )
4 펼침 유지·설명:        O / X
5 자동진행 중 자금:      O / X
6 라이벌 줄:             O / X / 라이벌전 달을 못 만남
7 잘림·오조작:
전보다 나아졌나 / 아쉬운 것:
```

## 9. 알려진 문제

- 단계형 투자의 자동 스위치는 누름이 한 번 늘었습니다(2-3).
- 360px 이상에서 할 일 칸이 79px 내려갔습니다(1절).
- 320px에서는 상태 칸의 "낮음·주의" 글자가 빠지고 색과 테두리로만 표시됩니다. 색을 구분하기 어려운 사람에게는 약합니다(선수 탭의 막대에는 그대로 있음).
- 자산 탭의 "자동"과 "사기" 버튼이 나란히 붙어 있습니다(각각 48px 높이, 84·60px 폭). 잘못 눌러 사는 일이 생길 수 있어 실제 폰에서 봐야 합니다.
- 라이벌 소식은 진행 요약에만 나옵니다. 요약을 보지 않고 넘어가면 예전처럼 기록 탭의 소식에서만 볼 수 있습니다.
- 상태 요약을 플레이 탭에만 두었으므로 리그·자산·기록 탭에서는 컨디션이 보이지 않습니다.
