# 폰으로 3분 확인: v0.11.1의 플레이 화면

**v0.11.2에서 화면이 다시 바뀌어 이 문서의 절차는 더 맞지 않습니다. 지금 확인할 것은 `docs/stage11-2-phone-check.md`입니다.** 이 문서는 실행된 적이 없습니다. 개발 환경에는 폰이 없고 배포 주소에 접속할 수 없습니다. 아래 표는 비어 있습니다.

주소: https://0jae104.github.io/progamer-career/ (타이틀 맨 아래 숫자가 `v0.11.1`인지 먼저 봅니다. 예전 숫자면 새로 고칩니다. 예전 버전으로 열어 둔 탭은 닫습니다)

하던 커리어로 해도 됩니다. 이 확인은 저장을 지우지 않습니다. 자동 관리는 **직접 켜기 전에는 돈을 쓰지 않습니다.**

## 해 볼 것 (다섯 가지, 약 3분)

| # | 할 일 | 이렇게 되면 통과 | 누른 횟수 |
|---|---|---|---|
| 1 | **할 일 바꾸기**: "이번 달 할 일"의 큰 버튼 → 다른 것 하나 | 두 번 눌러 바뀌고 목록이 다시 접힌다 | 목표 2번 |
| 2 | **자동 관리 켜기**: "자금 …" 줄 → "심리 상담"의 "매달 자동 꺼짐" | 두 번 눌러 "켜짐"이 되고, 자금 줄 오른쪽에 "자동 관리 1개 켜짐"이 보인다 | 목표 2번 |
| 3 | **한 달 진행**: 맨 아래 왼쪽 "N월 진행" | 창이 뜨지 않고 화면 위쪽에 "N월 진행 · 몇 승 몇 패 · 월급 +… · 자동 관리 −220만 · 컨디션 …" 한 줄이 나온다. "결과 자세히"를 누르면 경기 기록과 자동 관리 내역이 펼쳐진다 | 목표 1번 |
| 4 | **다음 중요한 순간까지**: 맨 아래 오른쪽 "다음 중요한 순간 ▶▶" | 평범한 달은 창 없이 넘어가고, 사건 선택·경기 준비·계약 같은 창에서 멈춘다. 아무 창 없이 멈췄다면 화면 위쪽에 이유(다음 달 라이벌전, 컨디션 등)가 적혀 있다 | 목표 1번 |
| 5 | **자동 관리 끄기**: "자금 …" 줄 → "매달 자동 켜짐" | 두 번 눌러 꺼지고, 다음 달 요약에 "자동 관리 −…"가 없다 | 목표 2번 |

덤으로 볼 것

- 사건에서 선택을 고르면 결과 창이 따로 뜨지 않고 화면 맨 위에 결과가 나온다.
- 버튼이 손가락으로 누르기에 충분히 크고, 글자가 작아서 읽기 힘든 곳이 없다.
- 맨 아래 두 버튼이 폰의 하단 바에 가려지지 않는다.
- 진행한 뒤 화면이 맨 위로 튀지 않는다.
- 탭이 셋(플레이 / 커리어 / 기록·설정)이고, 능력치·리그·라이벌은 "커리어"에, 소리·백업은 "기록·설정"에 있다.
