# 소리 자산 (v0.11.0)

**음원 파일은 하나도 없습니다.** 모든 효과음은 `js/ui.js`의 `SND` 부분에서 브라우저의 Web Audio API로 실행 중에 합성합니다. 외부 음원, 샘플, 라이브러리, CDN을 쓰지 않습니다.

## 출처와 권리

| 항목 | 내용 |
|---|---|
| 제작 방식 | 이 프로젝트에서 직접 작성한 코드가 발진기(사각파·삼각파·톱니파·사인파)와 걸러 낸 잡음을 조합해 만듦 |
| 제작 | 이 저장소의 개발 과정에서 AI 도우미(Claude)가 작성. 음 높이·길이·음량은 아래 표의 숫자 그대로이며 다른 게임이나 음원을 듣고 따라 만든 것이 아님 |
| 외부 자산 | 없음 |
| 라이선스 | 저장소의 코드와 같음. 제3자의 권리가 걸린 소리 없음 |
| 참고 게임의 소리 | 추출·녹음·재현하지 않음 |

몇 개의 음이 올라가거나 내려가는 짧은 신호음입니다. 이런 단순한 음형이 세상의 어떤 소리와도 닮지 않았다고 보증할 수는 없습니다. 공개 전 점검 목록(`docs/release-checklist.md`)의 "타사 IP 혼동 검토"에 소리도 포함해 한 번 들어 보는 것을 권합니다.

## 큐 목록

음량은 발진기 하나의 최댓값이고, 전체에 0.42가 한 번 더 곱해집니다.

| 큐 | 언제 | 구성 | 길이 |
|---|---|---|---|
| `tap` | 전략 선택, 체험하기, 소리 켜기 | 사각파 240 → 190Hz, 음량 0.07 | 0.07초 |
| `start` | "경기 시작" | 잡음(800Hz 대역) + 톱니파 110 → 220Hz + 삼각파 330Hz | 0.55초 |
| `setw` | 관전 중 세트를 가져옴 | 삼각파 523Hz, 784Hz | 0.27초 |
| `setl` | 관전 중 세트를 내줌 | 삼각파 392Hz, 294Hz | 0.32초 |
| `tension` | 승부처 선택지가 나타날 때 | 잡음(500Hz 대역, 작게) + 톱니파 147, 165, 196Hz | 0.7초 |
| `ok` | 승부처 성공 | 삼각파 523, 659, 784, 1047Hz | 0.37초 |
| `fail` | 승부처 실패 | 사인파 330 → 233Hz | 0.36초 |
| `win` | 시리즈 승리(결승 제외) | 삼각파 523, 659, 784Hz 뒤 1047Hz | 0.86초 |
| `winbig` | 결승 승리 | 삼각파 523, 659, 784, 1047Hz 뒤 1319Hz + 사인파 659Hz + 잡음(1400Hz 대역) | 1.4초 |
| `lose` | 시리즈 패배 | 사인파 262Hz, 196Hz | 0.81초 |

배경음(반복 재생)은 없습니다.

## 재생 조건

- **사용자가 화면을 처음 누른 뒤에만** 오디오를 켭니다(모바일 브라우저의 자동 재생 제한). 그 전의 큐는 조용히 건너뜁니다.
- 기본값은 **켜짐**입니다. 끄는 곳: 타이틀 화면의 "소리 켜짐/꺼짐", 게임 안 기록 탭, 경기 창 오른쪽 위. 어디서든 한두 번 누르면 됩니다.
- 설정은 `pg_opt_v1`(이 기기의 브라우저)에 저장됩니다. 커리어 저장, 백업 파일과는 별개입니다.
- 탭이 숨겨지거나 화면이 잠기면 오디오를 멈추고, 돌아오면 설정이 켜져 있을 때만 다시 켭니다.
- 같은 큐는 0.09초 안에 겹쳐 내지 않습니다.
- "동작 줄이기"(prefers-reduced-motion)는 화면 효과만 줄입니다. 소리와는 별개의 설정입니다.
- 폰의 무음 스위치(아이폰)나 미디어 음량이 0이면 들리지 않습니다. 게임이 그것을 바꾸지는 않습니다.

## 소리를 낼 수 없을 때

Web Audio가 없는 브라우저, 오디오 생성이 막힌 환경, 재생이 거부된 경우 모두 **소리 없이 같은 결과로 진행**됩니다. 소리 코드는 전부 예외를 삼키고, 경기 판정과는 연결되어 있지 않습니다. 음원 파일이 없으므로 "파일을 받지 못함(404)"은 일어날 수 없습니다.

## 오프라인과 갱신

음원 파일이 없어서 서비스 워커의 보관 목록(`sw.js`의 9개 파일)은 그대로입니다. 소리는 `js/ui.js`와 함께 보관되고 함께 갱신됩니다.

## 확인한 환경

| 환경 | 확인 |
|---|---|
| PC 헤드리스 크롬(자동 검사) | 큐가 순서대로 요청되고 오디오가 실행 중일 때 재생 호출이 됨, 음소거, 설정 유지, 숨겨진 탭에서 정지, 오디오가 없는 환경에서 진행. **스피커로 들어 본 것은 아님** |
| 실제 폰(안드로이드 크롬, 삼성 인터넷, iOS 사파리) | **미실행**. 실제로 어떻게 들리는지, 음량이 적당한지, 무음 스위치와 블루투스에서의 동작은 확인하지 못함 |
| 사람이 들어 본 평가 | **없음** |

소리가 실제로 좋은지, 거슬리는지는 `docs/stage11-phone-playtest.md`의 3번 질문으로 확인합니다.
